# v1.0 — Shell 擴充 + 全面測試

## 目標

將 `sh` 從簡易指令執行器升級為支援 POSIX shell 主要功能的直譯器，
然後透過 `sh` 執行測試腳本，驗證 `posix/tools/` 下所有工具的正確性，並修正發現的錯誤。

## 擴充項目（按優先順序）

### P0 — 立即需要（測試基礎）

| 項目 | 說明 |
|------|------|
| 修正 `$?` | 正確追蹤上一指令退出碼，目前寫死為 `"0"` |
| `test` / `[` 內建 | 條件測試為 shell 內建（目前為外部程式） |
| `eval` 內建 | 將字串視為命令解析執行 |
| `.` (dot) 內建 | 在當前 shell 執行腳本 |

| `exec` 內建 | 用命令取代 shell |
| `wait` 內建 | 等待背景工作 |
| `shift` 內建 | 移動位置參數 |
| `unset` 內建 | 刪除變數 |
| `set` 內建 | 設定位置參數與 shell 選項 |

### P1 — 進階語法

| 項目 | 說明 |
|------|------|
| 指令替換 `$(...)` | 捕獲命令輸出作為字串 |
| 算術展開 `$((...))` | 整數算術運算 |
| 位置參數 | `$@` `$*` `$#` `$0` `$1` `$2` ... |
| `$$` | 當前 shell PID |
| `$!` | 最後背景工作 PID |
| Tilde 展開 | `~` `~user` `~+` `~-` |
| `PS1` 設定 | 可自訂提示字元 |

### P2 — 控制流程

| 項目 | 說明 |
|------|------|
| `if/then/elif/else/fi` | 條件分支 |
| `for/do/done` | 列表迴圈 |
| `while/until/do/done` | 條件迴圈 |
| `case/esac` | 模式匹配 |
| `break` / `continue` | 迴圈控制 |
| Shell 函數 | `name() { ... }` |
| `return` | 從函數返回 |
| `trap` | 訊號處理 |

### P3 — 變數進階操作

| 項目 | 說明 |
|------|------|
| `${var:=word}` | 賦值預設值 |
| `${var:+word}` | 替換值 |
| `${var:?word}` | 未設定時顯示錯誤 |
| `${#var}` | 字串長度 |
| `${var%pattern}` `${var#pattern}` | 前綴/後綴移除 |
| Here-string `<<<word` | 字串餵入 stdin |
| Quoted heredoc `<<'EOF'` | 不展開變數 |
| Here-doc tab 去除 `<<-` | 忽略前導 tab |

### P4 — 執行環境強化

| 項目 | 說明 |
|------|------|
| Globbing | `*` `?` `[...]` 路徑展開 |
| 子 shell `(list)` | 子 shell 中執行 |
| 命令分組 `{ list; }` | 當前 shell 中分組 |
| `alias` / `unalias` 內建 | 別名管理 |
| `set -e` `set -u` `set -x` | Shell 選項 |
| `cd -` | 回到前一個目錄，支援 `OLDPWD` |

- 變數展開
- 指令替換 `$(...)`
- 算術展開 `$((...))`
- Tilde 展開
- Globbing

### 2. 引入執行上下文 `ShellContext`

```
struct ShellContext {
    vars: HashMap<String, String>,      // shell 變數
    exported: HashSet<String>,          // 已匯出標記
    positional: Vec<String>,            // $1 $2 ...
    last_status: i32,                    // $?
    last_bg_pid: Option<u32>,           // $!
    shell_pid: u32,                      // $$
    options: HashSet<String>,           // -e, -u, -x
    functions: HashMap<String, Ast>,     // 自訂函數
    aliases: HashMap<String, String>,    // 別名
    loop_level: usize,                   // break/continue 用
    ...
}
```

### 3. 引入 AST

將解析從執行分離：`tokenize → parse → expand → execute`

```
enum Ast {
    Command { argv: Vec<AstNode>, redirects: Vec<Redirect> },
    Pipeline { stages: Vec<Ast>, inverted: bool },  // ! 前置
    Sequence { left: Box<Ast>, right: Box<Ast>, op: SeqOp }, // ; && ||
    Background(Box<Ast>),
    If { cond: Box<Ast>, then: Box<Ast>, else_: Option<Box<Ast>> },
    For { var: String, words: Vec<String>, body: Box<Ast> },
    While { cond: Box<Ast>, body: Box<Ast> },
    Case { word: String, patterns: Vec<(Vec<String>, Box<Ast>)> },
    Function { name: String, body: Box<Ast> },
    Subshell(Box<Ast>),
    BraceGroup(Box<Ast>),
    Break(Option<usize>),
    Continue(Option<usize>),
    Return(Option<i32>),
}
```

### 測試腳本 (用 sh 本身寫)

每個測試腳本格式：

```sh
#!/bin/sh
# test_xxx.sh — 測試 xxx 功能

PASS=0
FAIL=0

assert_eq() {
    expected="$1"
    actual="$2"
    msg="$3"
    if [ "$expected" = "$actual" ]; then
        PASS=$((PASS + 1))
        echo "  ✓ $msg"
    else
        FAIL=$((FAIL + 1))
        echo "  ✗ $msg"
        echo "    expected: $expected"
        echo "    actual:   $actual"
    fi
}

# 測試案例
result=$(echo hello)
assert_eq "hello" "$result" "echo hello"

# 摘要
echo "---"
echo "PASS: $PASS  FAIL: $FAIL"
[ $FAIL -eq 0 ] && exit 0 || exit 1
```
