# Vim — Vi/Vim 編輯器

`vim`（Vi IMproved）是增強的 Vi 編輯器，由 Bram Moolenaar 於 1991 年首次釋出。Vi（Visual Editor）由 Bill Joy 於 1976 年為 BSD Unix 開發。Vim 提供模式編輯（普通/插入/視覺/命令行模式）、語法高亮、外掛系統、多級復原、緩衝區/視窗/頁籤管理。此實作使用 crossterm 在 xv8 上提供終端機編輯功能。
