# Ngettext — 複數形式訊息

`ngettext` 是 GNU gettext 的複數形式處理工具。不同語言對複數有不同規則（如英語：1 個 = "one"，其餘 = "many"；波蘭語有三種複數形式）。`ngettext` 根據數值選用對應的複數翻譯字串。POSIX 的 `ngettext` 命令允許 shell 腳本進行語境感知的多語言訊息輸出。
