# M4 — 巨集處理器

`m4` 是一個通用的巨集處理器（macro processor），由 Brian Kernighan 與 Dennis Ritchie 在 Unix V7 中實作。`m4` 掃描輸入文字，識別並展開巨集。內建巨集包括 `define`/`undefine`（定義巨集）、`include`（包含檔案）、`ifdef`/`ifelse`（條件判斷）、`eval`（數學運算）、`substr`/`translit`（字串操作）。`m4` 是 GNU Autoconf 的重要組件。
