# Locale — 語言環境設定

`locale` 顯示或設定語言環境（locale）環境變數。語言環境控制字元編碼、數字格式、日期格式、貨幣格式、排序規則等。POSIX 使用 `LC_*` 系列變數（`LC_ALL`、`LC_COLLATE`、`LC_CTYPE`、`LC_MONETARY`、`LC_NUMERIC`、`LC_TIME`、`LC_MESSAGES`）分離控制。
