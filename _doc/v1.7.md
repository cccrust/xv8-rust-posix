# v1.7 — ex, fc 工具

## 目標

實作 POSIX 選用工具（UP 選項）中的 `ex` 和 `fc`。

## ex — 行編輯器

基於 `ed` 原始碼擴充，支援更多 ex 風格的指令。

### 支援指令

| 指令 | 說明 |
|------|------|
| `a` | 在當前位置後插入文字 |
| `c` | 取代指定範圍的行 |
| `co` / `t` | 複製行到指定位置 |
| `d` | 刪除行 |
| `e` | 編輯新檔案 |
| `f` | 顯示/設定檔名 |
| `g` / `v` | 全域比對（v = 反向比對） |
| `i` | 在當前位置前插入文字 |
| `j` | 合併行 |
| `k` | 標記行 |
| `l` | 列表顯示（顯示特殊字元） |
| `m` | 移動行 |
| `n` / `#` | 顯示行號 |
| `p` / `P` | 顯示行 |
| `q` / `Q` | 離開 |
| `r` | 讀取檔案 |
| `s` | 搜尋取代 |
| `u` | 復原（stub） |
| `w` | 寫入檔案 |
| `x` / `wq` | 寫入並離開 |
| `z` | 捲動顯示 |
| `=` | 顯示行數 |
| `.` | 顯示當前行 |
| `$` | 跳到最后一行 |
| `%` | 顯示所有行 |

### 位址範圍

支援 `1,3p`、`%p`、`;`、`$`、`.` 等標準 ex 位址語法。

## fc — Shell 歷史指令

### 支援選項

| 選項 | 說明 |
|------|------|
| `-l` | 列出歷史記錄 |
| `-n` | 不顯示行號 |
| `-r` | 反向順序列出 |
| `-s` | 重執行歷史指令 |
| `-e editor` | 用編輯器編輯歷史指令後執行 |

### 實作細節

- 預設讀取 `$HOME/.sh_history`
- 可透過 `$HISTFILE` 環境變數指定歷史檔案
- 支援 `fc -s old=new cmd` 格式進行指令替換
