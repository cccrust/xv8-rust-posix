## eventfd 核心功能

- `eventfd2(initval, flags)` → FD
- `read()` — 讀取 8-byte u64 計數值（resets to 0, or decrements by 1 in semaphore mode）
- `write(val)` — 將 u64 加到計數值（wrapping add, max-1 limit）
- `EFD_SEMAPHORE` flag — read decrements by 1 instead of resetting to 0
- `EFD_NONBLOCK` flag — read on zero returns EAGAIN
- epoll 整合 — eventfd 在 `fd_readiness` 中回傳正確的 readable/writeable 狀態

## 發現的 Bug

`sys_eventfd2()` 未設定 `inner.readable = true` 和 `inner.writeable = true`，導致所有對 eventfd FD 的 read/write 失敗並回傳 `BadDescriptor`。已在 v4.1 中修復。
