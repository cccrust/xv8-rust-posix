## 核心功能

### memfd_create
- `memfd_create(flags)` → FD
- 分配一個匿名記憶體緩衝區（以 `Vec<u8>` 實現），初始為空
- `write()` 在當前 offset 處寫入資料，必要時擴展緩衝區
- `read()` 從當前 offset 處讀取資料
- `lseek()` 支援 SEEK_SET, SEEK_CUR, SEEK_END
- `MFD_CLOEXEC` 標誌（僅解析，fork+exec 時 FD 關閉尚未實作）
- 不涉及檔案系統操作

### pidfd_open
- `pidfd_open(pid, flags)` → FD
- 驗證目標 PID 是否存在；若不存在回傳 `ENOENT`
- `close()` 釋放 pidfd 表項目
- `fd_readiness()` 在目標行程結束時回傳 readable（僅 POLLIN）
- `read()` 回傳 `EBADF`（Linux 行為一致）
- 支援 `close()` 但不支援 `dup2()`（pidfd 不支援）

## 發現的 Bug

File slot 重複使用時，`sys_memfd_create()`、`sys_eventfd2()` 未重置 `inner.offset`，導致新建立的 FD 繼承前一個 slot 使用者的 offset 值。已在 v4.2 中修復（在 `sys_memfd_create` 和 `sys_eventfd2` 中添加 `inner.offset = 0`）。
