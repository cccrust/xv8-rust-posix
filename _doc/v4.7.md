## API 說明

```c
int timerfd_create(int clockid, int flags);
// clockid: CLOCK_REALTIME (0), CLOCK_MONOTONIC (1)
// flags: TFD_NONBLOCK (0x0800), TFD_CLOEXEC (0x20000)
// returns: file descriptor

int timerfd_settime(int fd, int flags,
                    const struct itimerspec *new_value,
                    struct itimerspec *old_value);
// flags: TFD_TIMER_ABSTIME (0x0001)

int timerfd_gettime(int fd, struct itimerspec *curr_value);

ssize_t read(int fd, void *buf, size_t count);
// reads u64 expiration count; blocks until timer fires
```

## 實作要點

1. **tick 驅動**：timerfd 使用 xv8 的 tick 計時器（100Hz，每 tick = 10ms）來驅動計時，將 `itimerspec` 轉換為 tick 計數做比較

2. **阻塞讀取**：`timerfd_read()` 支援 blocking mode，當計時器未到期時透過 `Channel::TimerTick` 進入 sleep，由 `clock_intr` 中呼叫的 `tick()` 喚醒

3. **週期計時器**：支援 `it_interval` 自動重載，每次到期後重新設定 `it_value_ticks = now + it_interval_ticks`

4. **非阻塞模式**：當 `TFD_NONBLOCK` 或計時器未 arm 時，`read()` 回傳 `EAGAIN`

5. **it_interval 轉換**：`timespec_to_ticks()` 將 sec/nsec 轉換為 xv8 tick 單位（1 tick = 10ms），捨棄 <10ms 的精度

## 相依性

- 依賴 `Channel::TimerTick` 與 `proc::sleep`/`wakeup` 機制（v3.x）
- 依賴 `clock_intr` 定時中斷（v1.x）
- 不使用 `epoll` 整合（可選，透過 `TimterTick` 喚醒）
