# v2.5 — xv8 Kernel epoll + async I/O + tokio compat + httpepoll ✅

## Summary

Implemented kernel-level epoll (`O_NONBLOCK`, `fcntl`, `epoll_create1`/`ctl`/`wait`, `poll`) in xv8, integrated with the async runtime reactor for zero-cost async TCP I/O. Added `xv8-tokio-compat` facade for `tokio::net::TcpStream`/`TcpListener`. All 15/15 QEMU tests pass (added `_httpepoll`).

## Architecture

```
xv8 kernel poll.rs (epoll_create1/ctl/wait)
    └── tcp handle_tcp path: data arrives → wakeup epoll
        └── xv8-async Reactor (epoll_fd + waker HashMap)
            └── io_async.rs (AsyncTcpStream poll_read/poll_write)
                └── xv8-tokio-compat (tokio::net facade)
                    └── _httpepoll testbin (fork + epoll HTTP server)
```

## Kernel Changes

### New: `xv8/kernel/src/poll.rs` (~400 lines)

- `EpollInstance` with `entries`, `triggered`, `waiters`
- `sys_epoll_create1(flags)` → allocate epoll instance, return fd
- `sys_epoll_ctl(epfd, op, fd, event)` → add/mod/del monitoring fd
- `sys_epoll_wait(epfd, events, max, timeout)` → sleep until events or timeout
- `notify(conn_ptr, events)` → called by `tcp::handle_tcp()` on data arrival, wakes epoll_wait
- `sys_poll(fds, timeout)` → traditional poll compatibility

### Modified: `xv8/kernel/src/file.rs`

- Added `nonblocking: bool` flag to `FileInner`

### Modified: `xv8/kernel/src/sysfile.rs`

- `O_NONBLOCK` flag supported in open
- `fcntl(F_GETFL)`/`fcntl(F_SETFL)` for setting nonblocking

### Modified: `xv8/kernel/src/net/tcp.rs`

- `recv()` returns `EAGAIN` when nonblocking + no data
- `handle_tcp()` calls `epoll::notify()` on data arrival

## Userspace Changes

### `xv8/user/src/syscall.rs`

- Added `epoll_create1`, `epoll_ctl`, `epoll_wait`, `poll`, `set_nonblocking`

### `xv8rust/xv8-async/src/reactor.rs` (NEW, 87 lines)

- `ReactorInner` with `epoll_fd` + `HashMap<usize, Waker>`
- `init()` → `epoll_create1`, stores `epoll_fd` in global `Mutex<Option<ReactorInner>>`
- `register_read(fd, waker)` → `epoll_ctl(ADD, fd, EPOLLIN)` + store waker
- `register_write(fd, waker)` → `epoll_ctl(ADD, fd, EPOLLOUT)` + store waker
- `poll(timeout)` → `epoll_wait()` → dispatch wakers

### `xv8rust/xv8-async/src/io_async.rs` (NEW, 154 lines)

- `AsyncTcpStream` with `poll_read`/`poll_write` — tries non-blocking recv, falls back to reactor registration
- `AsyncTcpListener` with `poll_accept` — same pattern

### `xv8rust/xv8-tokio-compat/` (NEW crate)

- `src/lib.rs` — `TcpStream` + `TcpListener` wrapping `AsyncTcpStream`/`AsyncTcpListener`
- `src/runtime.rs` — minimal tokio `Runtime` with `block_on` + `spawn`
- `src/time.rs` — `Sleep` future wrappers
