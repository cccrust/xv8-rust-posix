# v2.6 — POSIX Shell Integration into xv8 QEMU + Fix argv Propagation ✅

## Summary

Integrated the POSIX shell (`/sh`) and 100+ POSIX tools into the xv8 QEMU filesystem, replacing the minimal xv6-style builtins (`cat`, `echo`, `kill`, `ln`, `ls`, `mkdir`, `rm`, `sh`, `sleep`, `wc`). Created a 83-test POSIX shell behavior test suite (`shtest.sh`) that runs inside QEMU. Fixed the root cause of the shell entering interactive mode: `argc`/`argv` registers were clobbered before `main()` could read them. **All 83 shell tests pass inside QEMU (16/16 xv8 tests).**

## Part 1: POSIX Shell Integration

### xv8 User Binaries Cleanup

Old xv6-style builtin source files moved to `xv8/user/bin/_bak/` (kept for reference):
- `cat.rs`, `echo.rs`, `kill.rs`, `ln.rs`, `ls.rs`, `mkdir.rs`, `rm.rs`, `sh.rs`, `sleep.rs`, `wc.rs`

- **`xv8/test.sh`** — passes `shtest.sh` to `mkfs.sh` during test runs.
- **`xv8/user/Cargo.toml`** — removed `[[bin]]` entries for old builtins; added `_shtest` test binary entry.
- **`xv8/user/testbin/testrunner.rs`** — added `/_shtest` to `const TESTS` (16 total).

### Shell Test Suite

`xv8/shtest.sh` — 83 tests covering echo, variables, defaults, cmd substitution, arithmetic, redirections, pipes, exit codes, test/`[`, if/else, for/while loops, case, `&&`/`||`, set/shift, type, export, cd/pwd, functions, eval, continue/break, source, readonly.

### Shell Bugs Found (Workarounds in shtest.sh)

| Bug | Workaround |
|-----|-----------|
| `elif` keyword not parsed | `else if ... fi; fi` |
| Empty-string function args stripped | `check()` compares both `-z` and non-empty `=` |
| `[ "x" = "" ]` returns 0 (true) | Never pair empty+nonempty in `test` |
| Single quotes don't prevent expansion | Cosmetic only |

## Part 2: Fix argv Propagation (Root Cause)

### Problem

The kernel sets `a0=argc, a1=argv` and jumps to `_start`. But by the time `main()` calls `std::env::args()`, those **caller-saved registers** have been clobbered by the function call chain:

```
_start(argc, argv)
  → lang_start(main, argc, argv, sigpipe)  // _argc, _argv ignored!
    → main()
      → std::env::args()
        → from_stack() asm!("mv {0}, a0")  // ← a0 already garbage!
```

### Fix

Two-file change to store `argc`/`argv` in `static mut` globals before any function call:

**`xv8rust/xv8-libc/src/args.rs`** — added static storage + `init()`; `from_stack()` reads from statics instead of inline asm.

**`xv8rust/xv8-user-std/src/runtime.rs`** — `_start()` calls `xv8_libc::args::init()` before `lang_start()`.

No `AtomicUsize` used (would trap via `csrr sstatus` on riscv64 user mode). Plain `static mut` is safe here because `_start()` is single-threaded with no interrupts.
