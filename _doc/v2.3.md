# v2.3 — HTTP 支援（xv8 QEMU 內 httpd + httpget 全雙向通過）✅

## 目標

在 xv8 QEMU 內執行 HTTP 伺服器與客戶端。不使用任何第三方 HTTP crate（如 ureq、tiny_http），改以 `libnet` 平台抽象層 + 原始 `TcpStream` 實作最小 HTTP/1.0。

## 新增檔案

| 檔案 | 說明 |
|------|------|
| `net/tools/src/bin/httpget.rs` | HTTP GET 客戶端 — URL 解析、`TcpStream::connect`、送出 `GET` request、讀取並印出 response body |
| `net/tools/src/bin/httpd.rs` | HTTP 伺服器 — `TcpListener::bind`、解析 request、回應固定 HTML（`hello from xv8!`）後結束 |
| `xv8/user/testbin/http.rs` | QEMU testbin — fork httpd → nanosleep 500ms → fork httpget → wait → 驗證退出碼 |

## 修改檔案

| 檔案 | 修改 |
|------|------|
| `net/tools/Cargo.toml` | 新增 `httpget`、`httpd` 兩個 `[[bin]]` entry（`required-features = []`，host+riscv64 雙目標） |
| `xv8/user/Cargo.toml` | 新增 `_http` testbin entry |
| `xv8/user/testbin/testrunner.rs` | 加入 `/_http` 至 `const TESTS` |

## 設計

### httpget.rs

- 支援 `http://host[:port]/path` URL 格式
- 預設 port 80
- `HTTP/1.0`（不支援 keep-alive、chunked encoding）
- Response buffer: `vec![0u8; 4096]`（heap 配置，避免 xv8 16KB 堆疊溢位）
- 超時：`set_read_timeout(Some(Duration::from_secs(10)))`

### httpd.rs

- 單次服務：處理一個請求後 `break` 結束（避免 kill 後 accept 阻塞問題）
- Response: `HTTP/1.0 200 OK` + `Content-Type: text/html` + `Content-Length: 51` + `Connection: close`
- Body: `<html><body><h1>hello from xv8!</h1></body></html>`

### 注意

- xv8 kernel `tcp_connect()` 為無限 busy-wait（無 timeout），故 `tcp_accept()` 也無法被 `kill` 中斷 — httpd 改為 `break` 自願結束
- 不使用任何外部 HTTP crate，純 `TcpStream` 操作，確保 host + riscv64 雙目標編譯
