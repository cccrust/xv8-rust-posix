# v3.4 — io::copy, empty/repeat/sink, fs::canonicalize

## 目標

補上 `io::copy()`、`io::empty()`/`io::repeat()`/`io::sink()`、`fs::canonicalize()` 三個 Rust std 中常用的 IO 功能，並確認 `File::seek(SeekFrom::End)` 和 `OpenOptions::append(true)` 已正確實作。

## 設計

### P1 — io::copy()

Rust std 的 `io::copy()` 將資料從 `Read` 串流複製到 `Write` 串流，使用 4096 byte 的堆疊緩衝區：

```rust
pub fn copy<R: Read + ?Sized, W: Write + ?Sized>(reader: &mut R, writer: &mut W) -> Result<u64> {
    let mut buf = [0u8; 4096];
    let mut total = 0;
    loop {
        let n = reader.read(&mut buf)?;
        if n == 0 { break; }
        writer.write_all(&buf[..n])?;
        total += n as u64;
    }
    Ok(total)
}
```

### P2 — io::empty() / io::repeat() / io::sink()

三個 noop IO 類型：

| 類型 | Read | Write | 行為 |
|------|------|-------|------|
| `Empty` | `read()` → `Ok(0)` | — | 永遠不產生資料 |
| `Repeat(u8)` | `read(buf)` → 用指定 byte 填滿 buf | — | 無限產生相同 byte |
| `Sink` | — | `write(buf)` → `Ok(buf.len())`, `flush()` → `Ok(())` | 吞掉所有寫入 |

直接 struct + trait impl，無 state machine 或 buffer。

### P3 — fs::canonicalize()

xv8 無 `getcwd` syscall，故使用 `env::var("PWD")` 取得當前目錄：

1. 若路徑以 `/` 開頭，直接使用；否則 prepend `PWD`
2. 依 `/` 分割，用 Vec 作為 stack：
   - `""` 或 `"."` → 跳過
   - `".."` → pop 最後一個 component（若存在）
   - 其他 → push
3. 以 `/` 重新拼接

無 `open()`/`stat()` 驗證 — 純字串操作。
