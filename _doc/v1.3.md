# v1.3 — Shell 語法修正

**目標：修掉 bash.rs 與 sh.rs 的三個已知 bug，讓 shell 基本運算和變數展開正常。**

---

## 修改內容

### bash.rs

| 行號 | 問題 | 修正 |
|------|------|------|
| 193 | 雙引號內 `$((` 的 format 字串 `$(({})` 少一個 `)` | 改為 `format!("$(({}))", expr)` |
| 229 | Lexer word delimiter 集合缺少 `$`，導致 `pre$((1+1))post` 這類內嵌變數/運算不會被展開 | 加入 `$`：`" \t\n;|&(){}<>!$"` |
| 251 | `$((` expander 的 depth 初始為 1，只消耗一個 `)`，第二個 `)` 殘留在輸出中 | 改為 `let mut depth = 2;` |

### sh.rs

| 行號 | 問題 | 修正 |
|------|------|------|
| 68-70 | `ShellContext::new()` 未載入 OS 環境變數，`$HOME` 等變數展開為空 | 加入 `for (key, value) in std::env::vars() { ctx.vars.insert(key, value); }` |

---

## 驗收結果

```bash
echo $((1+1))       # → 2
echo $(echo hi)     # → hi
echo $HOME          # → /root（或實際值）
```
