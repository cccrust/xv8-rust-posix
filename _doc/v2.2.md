# v2.2 — QEMU async smoke test

**目標：在 QEMU 中實際執行 xv8-async TCP echo server**

---

## 這版做了什麼

### async_echo posix 工具
- 新增 `posix/tools/src/bin/async_echo.rs` — 基於 xv8-async 的 TCP echo server
- 監聽 loopback port 27001，accept 後 read/write echo
- 使用 `xv8-async` Runtime + AsyncTcpListener
- 為 riscv64-only（host 端為空 main）
- 作為 posix tool 編譯，透過 `mkfs.sh` 自動嵌入 `fs.img`

### _async QEMU 測試
- 新增 `xv8/user/testbin/async.rs` — QEMU 整合測試
- fork + exec async_echo
- `tcp_connect()` → `tcp_send()` → `tcp_recv()` 驗證 echo 功能
- 整合進 testrunner：`/_async` 為第 12 個測試項目

### 驗收條件
- `xv8/test.sh` 新增 async 測試項目 `_async` 且通過
- QEMU 中 async TCP echo server 可啟動並回應
