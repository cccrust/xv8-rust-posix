# v2.2 — xv8rust/net bridge + 網路工具移植

## 目標

建立 `xv8rust/xv8-net/` crate，提供 `std::net` 相容 API 讓 `net/` 工具可在 riscv64 上編譯執行。

## 新增/修改檔案

| 檔案 | 狀態 | 行數 |
|------|------|------|
| `xv8rust/xv8-net/Cargo.toml` | **新增** | 7 行 |
| `xv8rust/xv8-net/src/lib.rs` | **新增** | 3 行 |
| `xv8rust/xv8-net/src/net.rs` | **新增** | 492 行 |
| `xv8rust/Cargo.toml` | 修改 | 加入 `xv8-net` 到 workspace members |

## xv8-net crate 架構

```
xv8rust/xv8-net/
├── Cargo.toml          # 依賴: xv8-user-std, xv8-libc
├── src/
│   ├── lib.rs          # #![no_std], pub mod net;
│   └── net.rs          # 492 行 - 完整 std::net 相容層
```

### 提供的型別與 API

| 型別 | 匹配 std::net 方法 |
|------|-------------------|
| `Ipv4Addr` | `new`, `octets`, `UNSPECIFIED`/`LOCALHOST`/`BROADCAST`, Display, FromStr, From\<[u8;4]\>, Into\<u32\> |
| `IpAddr` | `V4(Ipv4Addr)`, `is_unspecified`, `is_loopback` |
| `SocketAddrV4` | `new`, `ip`, `port` |
| `SocketAddr` | `V4(SocketAddrV4)`, `new`, `ip`, `port`, Display, FromStr |
| `ToSocketAddrs` | 支援 `SocketAddr`, `(IpAddr,u16)`, `(&str,u16)`, `&str`, `String`, `u16` |
| `TcpStream` | `connect`, `peer_addr`, `set_read/write_timeout`, `set_nodelay`, `shutdown`, `try_clone`, `Read`+`Write` |
| `TcpListener` | `bind`, `accept`, `local_addr`, `set_nonblocking`, `incoming()` |
| `UdpSocket` | `bind`, `send_to`, `recv_from`, `set_read/write_timeout`, `fd` |
| `Shutdown` | `Read`, `Write`, `Both` |
| `lookup_host` | IP 直接解析；DNS 待後續整合 |

### Re-export（供呼叫端使用）

- `Read`, `Write`, `Error`, `ErrorKind`, `Result` — 來自 `xv8_user_std::io`
- `Duration` — 來自 `xv8_user_std::time`

### 設計

- `#![no_std]` + `extern crate alloc`
- 內部委派（delegation）至 `xv8_user_std::net` 基礎型別
- `set_read_timeout` / `set_write_timeout` 為 no-op stub（xv8 核心無 per-socket timeout）
- 轉換層在位址型別間轉換（`xv8_user_std::net::SocketAddr` ↔ `xv8_net::net::SocketAddr`）

## 編譯驗證

```bash
# host 目標
cargo build --release -p xv8-net                     # ✅ aarch64-apple-darwin

# riscv64 目標
cargo build --release -p xv8-net \
  --target riscv64gc-unknown-none-elf                 # ✅ riscv64gc-unknown-none-elf

# 零警告，零錯誤
```
