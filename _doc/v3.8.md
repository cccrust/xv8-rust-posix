# v3.8 — Testing: thread_v3 QEMU test

## 目標

新增 QEMU 整合測試 `_thread_v3`，涵蓋 v3.3+ 的 thread API 功能。

## 實作

### 新增測試 binary：`_thread_v3`

`xv8/user/testbin/thread_v3.rs` 使用 raw clone syscall 模擬 Builder pattern 的測試：

| 測試 | 說明 |
|------|------|
| `test_builder_pattern` | clone + pipe join，確認 child 返回值 42 |
| `test_named_thread` | 在 TCB 中設定 name pointer，child 從 tp 讀取 name |
| `test_stack_size` | 8KB stack clone，確認可正常執行 |
| `test_multi_named` | 3 threads 各自有不同名稱（thread-1, thread-2, thread-3），parent 驗證每個 child 名稱正確 |

### 整合

- 新增 `xv8/user/Cargo.toml` bin entry
- 新增 `xv8/user/testbin/testrunner.rs` ALL_TESTS 項目
- 更新 `xv8/test_core.sh` 測試清單

### Known Limitation

Host-side unit test (`#[cfg(test)]`) 無法執行，因為 `xv8-libc` 使用 RISC-V inline asm，無法在 host (aarch64/x86_64) 編譯。所有測試皆透過 QEMU 執行。

## 測試結果

18 個 QEMU 測試全部通過：

| 類別 | 數量 | 狀態 |
|------|------|------|
| Core（含 thread_v3） | 9 | ✅ |
| Net | 6 | ✅ |
| Async | 3 | ✅ |
| **總計** | **18** | **✅** |
