# v2.1 — xv8 核心 TCP 支援

## 目標

在 xv8 核心網路堆疊中加入完整 TCP 協定支援（狀態機、socket 表、syscall），並通過 QEMU loopback 驗證。

## TCP 核心實作（tcp.rs）

### TCP 狀態機

```
Closed → Listen → SynReceived → Established → ... → TimeWait → Closed
                → SynSent   → SynReceived → ...
```

完整狀態：Closed, Listen, SynSent, SynReceived, Established, FinWait1, FinWait2, CloseWait, LastAck, TimeWait

### TCP Socket 表

- 固定大小陣列（`NTCP` 個 slot）
- `alloc_port()` 分配動態埠號
- `find_listener()` 比對監聽 socket
- 支援 backlog（連線佇列）

### TCP 系統呼叫

| 編號 | 名稱 | 說明 |
|------|------|------|
| 108 | `tcp_socket()` | 建立 TCP socket |
| 109 | `tcp_bind(fd, port)` | 綁定埠號 |
| 110 | `tcp_listen(fd)` | 開始監聽 |
| 111 | `tcp_accept(fd)` | 接受連線（阻塞） |
| 112 | `tcp_connect(fd, ip, port)` | 主動連線（阻塞至握手完成） |
| 113 | `tcp_send(fd, buf, len)` | 傳送資料 |
| 114 | `tcp_recv(fd, buf, len)` | 接收資料（阻塞） |

### 使用者空間包裝

`xv8rust/xv8-user-std/src/net.rs` 提供 `TcpStream`、`TcpListener`、`UdpSocket` 等型別，透過 `xv8-libc` syscall 包裝呼叫核心。

TCP echo 測試流程：
1. `tcp_echo` 在 background 啟動，監聽 127.0.0.1:27000
2. `tcpecho` 用 `TcpStream::connect` 連入，送出 `hello!`
3. 伺服器原樣 echo 回，用戶端比對一致

## 已知限制

- 無重傳計時器（retransmit timer）
- 無壅塞控制（congestion control）
- 無 IPv6 支援
- QEMU user-mode NAT 無法從外部連入 guest
