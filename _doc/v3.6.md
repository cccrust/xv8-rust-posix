# v3.6 — Advanced API: lookup_host, CommandExt, UnixStream, panic::set_hook, Barrier

## 目標

補上 Rust std 中常見但缺少的 API：DNS resolution、Unix process extensions、Unix socket 抽象、panic hook、Barrier 同步原語。

## 實作

### P1 — net::lookup_host()

使用 UDP socket 向 DNS 伺服器（預設 8.8.8.8:53）查詢 A record：

```rust
pub fn lookup_host(name: &str) -> io::Result<Vec<SocketAddr>>
```

實作細節：
1. 先嘗試解析 dotted decimal IP → 直接返回
2. 建立 `UdpSocket：send_to` DNS query（標準 header + encoded name + type A）
3. `recv_from` 接收 response
4. 解析 ANCOUNT 記錄，提取 type A（1）且 rdlen=4 的記錄
5. 支援 DNS name 壓縮指標（0xC0 prefix）
6. 包含 `encode_dns_name()` 和 `parse_dns_name()` 輔助函數

### P2 — os::unix::process::CommandExt

```rust
pub trait CommandExt {
    fn uid(&mut self, id: u32) -> &mut Command;
    fn gid(&mut self, id: u32) -> &mut Command;
}
```

實作為 no-op（xv8 不支援 setuid/setgid fork），提供 trait 以滿足編譯相容性。

### P3 — os::unix::net::UnixStream

Unix domain socket 的 pipe-based 替代實作：

| 類型 | 說明 |
|------|------|
| `UnixStream` | 雙向通訊，`pair()` 使用 pipe() 建立配對 |
| `UnixStream::connect()` | 回傳 `Unsupported`（xv8 無 AF_UNIX） |
| `UnixListener` / `UnixDatagram` | 大部分功能回傳 `Unsupported` |

### P4 — panic::set_hook()

允許使用者註冊 panic hook：

```rust
pub fn set_hook(hook: Box<dyn Fn(&PanicInfo) + 'static>)
pub fn take_hook() -> Box<dyn Fn(&PanicInfo) + 'static>
pub(crate) fn run_hook(info: &PanicInfo)
```

實作使用 `AtomicBool` + `static mut Option<Box<dyn Fn>>`。`runtime.rs` 的 panic handler 在 `exit(1)` 前呼叫 `run_hook()`。

### P5 — sync::Barrier

```rust
pub struct Barrier { count: AtomicU32, total: u32, condvar: Condvar, mutex: Mutex<()> }

impl Barrier {
    pub const fn new(n: usize) -> Self;
    pub fn wait(&self) -> bool; // true = last thread to arrive
}
```

標準實作：最後一個到達的執行緒呼叫 `notify_all()` 喚醒所有等待者。
