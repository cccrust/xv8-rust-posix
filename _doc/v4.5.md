## inotify 核心功能

- `inotify_init1(flags)` → FD
- `inotify_add_watch(fd, path, mask)` → watch descriptor (wd)
- `inotify_rm_watch(fd, wd)` → 移除 watch
- `read(fd, buf, size)` → 讀取 `struct inotify_event` 陣列（每個事件含 wd, mask, cookie, len + 名稱，4-byte 對齊填充）
- 全域 inotify 表格（16 個 instance），每個 instance 含事件佇列、watch 列表、等待標記、WD 分配器
- `notify(dev, inum, mask, cookie, name)` — 遍歷所有 instance，比對 watch (dev, inum)，佇列匹配事件，喚醒等待行程

## 已知限制

- IN_MODIFY 僅在 `File::write()` 鉤住（檔案資料寫入）。未鉤住 O_APPEND 旗標的附加寫入路徑。
- IN_CLOSE_WRITE / IN_CLOSE_NOWRITE 尚未實作（需要 close 路徑改寫）。
- IN_ACCESS 讀取事件尚未鉤住。
- blocking read 未實作（回傳 EAGAIN；使用 poll/epoll_wait 等待）。
- rename 中 old-parent unlink 總是寫入 offset 0（既有 bug，非 inotify 導致）。
