# v5.7 xv8-container 工具

## 目標

提供 Docker-like CLI 工具 `xv8-container`，方便使用者管理容器。支援命令：

```
xv8-container run   <name> <command> [args...]  # 執行容器
xv8-container exec  <name> <command> [args...]  # 進入運行中容器 (stub)
xv8-container ps                                # 列出容器 (stub)
xv8-container rm   <name>                      # 刪除容器 (stub)
xv8-container pull <image>                     # 下載 image (stub)
```

## 架構

### 二進位檔案

`xv8/user/bin/xv8_container.rs` — 使用者空間 CLI 工具，使用 `no_std` + sbrk allocator。

### 容器生命週期

```
xv8-container run mycontainer /bin/echo hello
  │
  ├─ fork()
  │    ├─ child: unshare(CLONE_NEWPID|NEWNS|NEWUTS)
  │    ├─ child: sethostname("mycontainer")
  │    ├─ child: cgroup attach
  │    ├─ child: pivot_root("/tmp/rootfs", "/tmp/rootfs/oldroot")
  │    ├─ child: chdir("/")
  │    └─ child: exec("/bin/echo", ["hello"])
  │
  └─ parent: write state → /var/lib/xv8-container/containers/<name>/
  └─ parent: wait() for exit code
```

### 狀態儲存

```
/var/lib/xv8-container/containers/<name>/
├── pid       # container PID
└── command   # container 執行的命令
```

文字格式（無 JSON 相依性）。

### CLI 實作

| 命令 | 狀態 | 說明 |
|------|------|------|
| `run` | ✅ 實作 | fork + unshare + pivot_root + exec |
| `exec` | 🔶 骨架 | 等待 setns 整合 |
| `ps` | 🔶 骨架 | 讀取狀態目錄 |
| `rm` | 🔶 骨架 | 清除狀態 |
| `pull` | 🔶 骨架 | 下載 rootfs |

## 測試

`user/testbin/container.rs` — QEMU 整合測試（28/28 通過）：

1. **設定階段**：建立 `/mycontainer/`、`/mycontainer/oldroot/`、`/mycontainer/dev/console`、cgroup
2. **Fork + 完整隔離**：
   - 子 process：`unshare(CLONE_NEWPID | CLONE_NEWNS | CLONE_NEWUTS)`
   - `sethostname("testcontainer")`
   - 附加到 cgroup
   - `pivot_root("/mycontainer", "/mycontainer/oldroot")`
   - 驗證隔離：`/mycontainer` 不可存取（新 root 下不存在）
   - 驗證 `/oldroot` 可存取（原始 root 掛載於 put_old）
   - 驗證 `/dev/console` 存在
3. **父 process 驗證**：
   - `wait()` 子 process
   - 讀取 cgroup stats，確認 `testcontainer` 存在

### 注意

- `/tmp/` 在 xv8 預設檔案系統中不存在，容器 rootfs 必須建立在根目錄（如 `/mycontainer`）
- `mkdir` 不支援遞迴建立（parent 必須先存在）
