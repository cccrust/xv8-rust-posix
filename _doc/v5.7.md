# v5.7 dock8 容器工具 + nsopen/setns

## 目標

提供 Docker-like CLI 工具 `dock8`，支援容器管理。核心新增 `nsopen` 系統呼叫（編號 150），用於建立 namespace fd，並完整實作 `setns` 以實現 `exec` 進入容器。

```bash
dock8 run   <name> <command> [args...]  # 執行容器
dock8 exec  <name> <command> [args...]  # 進入運行中容器
dock8 ps                                # 列出容器 (stub)
dock8 rm   <name>                      # 刪除容器 (stub)
dock8 pull <image>                     # 下載 image (stub)
```

## 架構

### 使用者空間二進位檔案

`xv8/user/bin/dock8.rs` — 使用者空間 CLI 工具，使用 `no_std` + sbrk allocator。

### 核心新增：`nsopen` 系統呼叫 (150)

由於 xv8 沒有 `/proc` 檔案系統，無法使用 Linux 的 `open("/proc/<pid>/ns/<type>")` 模式。因此新增專用系統呼叫：

```rust
nsopen(pid: usize, nstype: u32) -> Fd
```

- `nstype`: 0=Mount, 1=Cgroup, 2=Uts, 3=Ipc, 4=User, 5=Pid, 6=Net
- 回傳一個 `FileType::NsFd { ns_proxy: Arc<NsProxy>, nstype }` fd
- `ns_proxy` 從目標 process 的 `data.ns` 複製並包裝為 `Arc<NsProxy>`

### 核心改進：`setns` 完整實作

先前 `sys_setns` 回傳 `NotImplemented`。現已實作：

1. 從 fd 讀取 `FileType::NsFd`
2. 取出儲存的 `NsProxy` 與 `nstype`
3. 使用 `clone_with_override()` 複製當前 ns，僅取代指定類型
4. 設定 `data.ns = Some(new_ns)`

`NsProxy::clone_with_override()` 方法：
```rust
pub fn clone_with_override(&self, nstype: NsType, source: &Self) -> Self
```

### 容器 exec 流程

```
dock8 exec mycontainer /bin/ls
  │
  ├─ 讀取 /var/lib/dock8/containers/mycontainer/pid → 取得 target_pid
  ├─ fork()
  │    ├─ child: nsopen(target_pid, 5)           → 取得 PID namespace fd
  │    ├─ child: setns(ns_fd, 0)                  → 加入容器 namespace
  │    ├─ child: exec("/bin/ls", [])              → 在容器內執行
  │    └─ parent: wait() 取得 exit code
  └─ 印出 "exec in mycontainer exited with code 0"
```

### 容器生命週期 (run)

```
dock8 run mycontainer /bin/echo hello
  │
  ├─ fork()
  │    ├─ child: unshare(CLONE_NEWPID|NEWNS|NEWUTS)
  │    ├─ child: sethostname("mycontainer")
  │    ├─ child: pivot_root("/tmp/rootfs", "/tmp/rootfs/oldroot")
  │    ├─ child: chdir("/")
  │    └─ child: exec("/bin/echo", ["hello"])
  │
  └─ parent: write state → /var/lib/dock8/containers/<name>/
  └─ parent: wait() for exit code
```

### 狀態儲存

```
/var/lib/dock8/containers/<name>/
├── pid       # container PID
└── command   # container 執行的命令
```

文字格式（無 JSON 相依性）。

## 注意

- `/tmp/` 在 xv8 預設檔案系統中不存在 — 容器 rootfs 必須使用根目錄路徑
- xv8 無 `/proc`，exec 使用 `nsopen` 替代 Linux 的 `open("/proc/<pid>/ns/pid")`
- `NsFd` 的 cleanup 由 `Arc<NsProxy>::drop` 自動處理（close handler 為空操作）
