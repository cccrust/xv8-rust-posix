# v3.7 — Async I/O Integration

## 目標

將 TcpStream/TcpListener 與 xv8-async epoll reactor 整合，提供 tokio-compat 風格的 async I/O。

## 實作（已在先前版本完成）

### xv8-async 層

`xv8rust/xv8-async/src/` 提供：

| 模組 | 內容 |
|------|------|
| `lib.rs` | 單執行緒 async runtime（Executor + Waker + JoinHandle + Sleep + YieldNow） |
| `reactor.rs` | epoll-based I/O reactor（register_read/write, unregister, poll_events） |
| `io_async.rs` | `AsyncTcpStream`（poll_read/poll_write）和 `AsyncTcpListener`（poll_accept） |

AsyncTcpStream 實作：
- `connect()`：建立 TCP socket，connect，設為 nonblocking
- `poll_read()`：呼叫 `tcp_recv()`；若回傳 EAGAIN，註冊 fd 到 epoll reactor，回傳 `Poll::Pending`
- `poll_write()`：同上，使用 `tcp_send()`

### xv8-tokio-compat 層

`xv8rust/xv8-tokio-compat/src/` 提供 tokio 相容包裝：

| 模組 | 內容 |
|------|------|
| `lib.rs` | `TcpStream`（wrap AsyncTcpStream + try_read/try_write）和 `TcpListener`（wrap AsyncTcpListener + poll_accept） |
| `io.rs` | `AsyncRead`/`AsyncWrite` trait + `AsyncReadExt`/`AsyncWriteExt` extension traits，實作於 `TcpStream` |
| `runtime.rs` | Runtime wrapper |
| `sync.rs` | 同步原語 |
| `time.rs` | 時間原語 |

### AsyncRead + AsyncWrite 實作

```rust
impl AsyncRead for TcpStream {
    fn poll_read(self: Pin<&mut Self>, cx: &mut Context, buf: &mut ReadBuf) -> Poll<Result<()>>
}
impl AsyncWrite for TcpStream {
    fn poll_write(self: Pin<&mut Self>, cx: &mut Context, buf: &[u8]) -> Poll<Result<usize>>
    fn poll_flush(self: Pin<&mut Self>, cx: &mut Context) -> Poll<Result<()>>
    fn poll_shutdown(self: Pin<&mut Self>, cx: &mut Context) -> Poll<Result<()>>
}
```
