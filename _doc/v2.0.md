# v2.0 — users/who 強化 + 小型選用工具

## 目標

強化使用者查詢相關工具（users、who、logname、last），並新增三個小型選用工具（rev、col、look）。

## 新增/修改工具

### who 強化

| 選項 | 說明 |
|------|------|
| `-a` | 處理所有資訊（預設） |
| `-b` | 顯示最後啟動時間 |
| `-H` | 顯示表頭 |
| `-q` | 快速模式（只顯示名稱 + 人數） |
| `-r` | 顯示執行層級 |
| `-T` | 顯示終端機狀態（+/-） |
| `-u` | 顯示閒置時間 |

### users 強化

改用 `libc::getutxent()` 正規 API，支援主機原生 utmpx 讀取。riscv64 上回傳 `root`。

### last

讀取 `utmpx` 並顯示最近登入記錄，最多 20 筆。支援 host（unix）平臺，riscv64 顯示不支援訊息。

### rev

反轉每一行的字元順序。

範例：
```
$ echo hello | rev
olleh
```

### col

過濾反向換行（reverse line feeds, SO/SI 控制字元）。

支援過濾：
- SO (U+008D) / SI (U+008E) — 反向列印標記
- BS (U+0008) — 倒退字元
- BEL (U+0007) — 忽略
- CR (U+000D) — 忽略

### look

字典查詢工具，顯示以指定前綴開頭的所有單字。

支援多個字典路徑：
- `/usr/share/dict/words`
- `/usr/share/dict/web2`
- `/usr/local/share/dict/words`

## 跨平臺注意事項

- `who`、`users`、`last` 在主機端（unix）使用 `libc::getutxent()` 讀取登入記錄
- riscv64 上無多使用者概念，`who`/`users` 回傳 `root`，`last` 顯示不支援
- `rev`、`col`、`look` 純文字處理，跨平臺無差異
