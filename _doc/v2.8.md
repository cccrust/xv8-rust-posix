# v2.8 — Async HTTP Server Test (xv8-tokio-compat)

## Summary

Added `_axum` test: an async HTTP server inside xv8 using `xv8-tokio-compat` traits
(`TcpListener`, `AsyncReadExt`, `AsyncWriteExt`, `Runtime`) that validates the full
async I/O pipeline (bind, accept, read, write_all) via the `xv8-async` runtime.

## Changes

### New: `_axum` test binary
- `xv8/user/testbin/axum.rs` — forks; child runs `Runtime::block_on` with
  `TcpListener::bind` + async read/write; parent connects, sends GET, checks
  response body for "ok"

### Added: `xv8-tokio-compat` I/O + sync traits
- `xv8-tokio-compat/src/io.rs` — `ReadBuf`, `AsyncRead`, `AsyncWrite`,
  `AsyncReadExt` (read), `AsyncWriteExt` (write_all), `TcpStream` impls
- `xv8-tokio-compat/src/sync.rs` — oneshot channel via `Arc<Mutex<Inner>>`

### Fix: reactor initialization
- `xv8-async/src/reactor.rs` — added `ensure_init()`, made `init()` idempotent
  (guard against double init)
- `xv8-async/src/lib.rs` — `Runtime::block_on` now calls `reactor::ensure_init()`
  before starting the event loop. Without this, async I/O (`TcpListener::accept`,
  `TcpStream::read`) silently hung because epoll was never created.

### Fix: test filter exact match
- `xv8/user/testbin/testrunner.rs` — changed `test_short.starts_with(frag)` to
  `test_short == frag`. Previously "http" prefix-matched "httpepoll", causing
  the net test script to run httpepoll (whose binary was absent from fs.img)

### Fix: QEMU port 8080 removal
- `xv8/.cargo/config.toml` — removed `hostfwd=tcp::8080-:8080` (port was in
  use on dev host; no test uses port 8080)

### New: modular test scripts
- `xv8/test_xxx.sh` scripts replace the single monolithic `test.sh`:
  - `test_core.sh` — 7 kernel tests (fast, no posix/net cross-compile)
  - `test_async.sh` — 3 async tests (fast, no posix/net cross-compile)
  - `test_net.sh` — 6 networking tests (uses full mkfs.sh)
  - `test_shell.sh` — 1 shell test / 93 TAP subtests (uses full mkfs.sh)
  - `test.sh` — runs all four and aggregates pass/fail

## Bug Fixes

| Bug | Root Cause | Fix |
|-----|-----------|-----|
| `_axum` hangs | `reactor::init()` never called; reactor was None, epoll never created | `Runtime::block_on` calls `ensure_init()` |
| Net tests include httpepoll | `starts_with("http")` matched "httpepoll" | Changed to exact match `==` |
| QEMU start failure | Port 8080 in use on host | Removed hostfwd rule for 8080 |
| Kernel panic on `fork_ret exec` | `init` binary not on fs.img in core/async tests | Added `init` to required files in test scripts |
