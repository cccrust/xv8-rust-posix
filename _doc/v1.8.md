# v1.8 — iconv 編碼擴充

## 目標

擴充 `iconv` 工具支援的編碼轉換，從原本僅支援 UTF-8/ASCII/Latin1 三種擴充到十餘種編碼。

## 新支援編碼

| 編碼 | 說明 |
|------|------|
| UTF-16LE / UTF-16BE | 16-bit Unicode，支援 surrogate pair 處理 |
| UTF-32LE / UTF-32BE | 32-bit Unicode |
| ISO-8859-2 (Latin-2) | 中歐/東歐語言 |
| ISO-8859-3 (Latin-3) | 南歐語言 |
| ISO-8859-4 (Latin-4) | 北歐語言 |
| ISO-8859-9 (Latin-5) | 土耳其語 |
| ISO-8859-15 (Latin-9) | 西歐語言（含 € 符號） |
| CP1252 (Windows-1252) | Windows 西歐 |
| CP437 | DOS 原始編碼 |
| CP850 | DOS Latin-1 |
| KOI8-R | 俄文 |

## 架構改進

重新設計轉換管線：

```
[位元組] → decode() → [Unicode codepoints] → encode() → [位元組]
```

- `decode()`：將輸入位元組依來源編碼解碼為 Unicode codepoints
- `encode()`：將 Unicode codepoints 依目標編碼編碼為位元組
- `canonicalize()`：統一編碼名稱（如 `utf8`、`UTF-8`、`utf-16le`、`UTF16LE` 等都對應到同一內部名稱）

UTF-8 解碼使用 `String::from_utf8_lossy()` 確保正確處理多位元組序列。UTF-16 支援 surrogate pair（U+10000 以上字元）。

## 驗收

```bash
# 基本轉換測試
printf "Caf\xc3\xa9" | iconv -f UTF-8 -t ISO-8859-15  # → 43 61 66 e9
printf "Hello" | iconv -f UTF-8 -t UTF-16LE            # → H.e.l.l.o. (LE byte order)
printf "ab" | iconv -f UTF-8 -t UTF-32BE               # → 00 00 00 61 00 00 00 62

# 雙向轉換正確
printf "Hello" | iconv -f UTF-8 -t UTF-16LE | iconv -f UTF-16LE -t UTF-8  # → Hello

# 非 ASCII 字元降級
printf "Caf\xc3\xa9" | iconv -f UTF-8 -t ASCII         # → Caf?

# 列舉支援編碼
iconv -l
```
