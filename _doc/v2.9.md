# v2.9 — 輕量 HTTP Framework（仿 axum Router API）

## 目標

在現有 `xv8-tokio-compat` + `xv8-async` 之上建立輕量 HTTP framework，
讓 xv8 使用者能以 axum 風格的 API 編寫非同步 HTTP 服務：

```rust
async fn hello() -> &'static str {
    "Hello from xv8!"
}

async fn greet(Path(name): Path<String>) -> String {
    format!("Hello, {}!", name)
}

fn main() {
    let rt = Runtime::new();
    rt.block_on(async {
        let app = Router::new()
            .route("/", get(hello))
            .route("/hello/:name", get(greet));
        let listener = TcpListener::bind(8080).await.unwrap();
        serve(listener, app).await;
    });
}
```

## 總體設計

```
xv8-tokio-compat 擴充
    sync: watch, mpsc, Notify
    time: timeout, interval
    macros: select!
    io: copy_buf, split

xv8-http (新 crate, #![no_std] + alloc)
    └── Request, Response, StatusCode, Method, Uri, HeaderMap, Body
    └── HTTP/1.1 請求解析器 (parse Request from &[u8])
    └── HTTP/1.1 回應序列化器 (Response → Vec<u8>)

xv8-router (新 crate, #![no_std] + alloc)
    └── Router { routes: Vec<Route> }
    └── Handler: async fn(Request) -> Response
    └── IntoResponse trait (String, &str, StatusCode, etc.)
    └── Extractor: Path<T>, Query<T>, Json<T>
    └── serve(listener, router)  (accept + dispatch + respond loop)

xv8/user/testbin/
    ├── _axum.rs  ← 改寫成用新的 Router API
    └── _httpd.rs ← 新 test: HTTP 檔案伺服器 (展示 router + extractor)
```

## 實施步驟

### Step 1: xv8-http crate（HTTP 型別 + 解析器）

```
xv8rust/xv8-http/
  ├── Cargo.toml       # 依賴 alloc, xv8-user-std (io, string)
  └── src/
      ├── lib.rs
      ├── method.rs    # Method (GET, POST, HEAD, etc.)
      ├── status.rs    # StatusCode (200, 404, 500, etc.)
      ├── uri.rs       # Uri { path, query }
      ├── header.rs    # HeaderName, HeaderValue, HeaderMap
      ├── request.rs   # Request<Body> { method, uri, headers, body }
      ├── response.rs  # Response<Body> { status, headers, body }
      └── parse.rs     # HTTP/1.1 請求解析器 (有限狀態機)
```

**核心型別：**

```rust
// method.rs
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Method {
    Get, Head, Post, Put, Delete, Connect, Options, Trace, Patch,
    Extension(String),
}

// status.rs
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct StatusCode(u16);
// 常數: OK, NOT_FOUND, INTERNAL_SERVER_ERROR, etc.

// uri.rs
#[derive(Debug, Clone)]
pub struct Uri {
    pub path: String,
    pub query: String,       // "key=val&key2=val2" (raw, 不含 '?')
}

// header.rs
#[derive(Debug, Clone)]
pub struct HeaderName(String);   // lowercase
#[derive(Debug, Clone)]
pub struct HeaderValue(Vec<u8>);
#[derive(Debug, Clone)]
pub struct HeaderMap(Vec<(HeaderName, HeaderValue)>);

// body.rs
#[derive(Debug, Clone, Default)]
pub struct Body(Vec<u8>);

// request.rs
#[derive(Debug)]
pub struct Request<B = Body> {
    pub method: Method,
    pub uri: Uri,
    pub headers: HeaderMap,
    pub body: B,
}

// response.rs
#[derive(Debug)]
pub struct Response<B = Body> {
    pub status: StatusCode,
    pub headers: HeaderMap,
    pub body: B,
}
impl Response<Body> {
    pub fn to_bytes(&self) -> Vec<u8> { /* 序列化 */ }
}
```

**解析器設計（parse.rs）：**

HTTP/1.1 請求解析實作為有限狀態機，逐 byte 掃描，不回退：

```
ParseState:
  Method        → 讀取 method token
  Uri           → 讀取 path + query
  Version       → 讀取 "HTTP/1.x"
  HeaderName    → 讀取 header name (到 ':')
  HeaderValue   → 讀取 header value (到 '\r\n')
  HeaderCR      → 檢查 header line 結尾 ('\r')
  Body          → 根據 Content-Length 讀取 body
  Done          → 完成

pub fn parse_request(bytes: &[u8]) -> Result<(Request<Body>, usize), ParseError>
  // 回傳 (request, consumed_bytes)
```

限制：不支援 chunked transfer encoding, upgrade, expect continue。

### Step 2: xv8-router crate（路由 + handler 分派）

```
xv8rust/xv8-router/
  ├── Cargo.toml       # 依賴 xv8-http, xv8-tokio-compat
  └── src/
      ├── lib.rs
      ├── router.rs     # Router struct + route 註冊
      ├── handler.rs    # Handler trait + 各類型別實作
      ├── extract.rs    # Path, Query, Json extractor
      ├── into_response.rs # IntoResponse trait + 預設實作
      └── serve.rs      # accept + dispatch loop
```

**Router 核心：**

```rust
// handler.rs
pub trait Handler<B = Body>: Clone + Send + 'static {
    type Future: Future<Output = Response>;
    fn call(&self, req: Request<B>) -> Self::Future;
}

// 自動實作 Handler 對 closures / fn pointers
impl<F, Fut, T> Handler for F
where
    F: Fn() -> Fut + Clone + Send + 'static,
    Fut: Future<Output = T>,
    T: IntoResponse,
{ /* ... */ }

// router.rs
pub struct Route<B = Body> {
    method: Method,
    path: String,              // "/hello/:name"
    params: Vec<String>,       // ["name"]
    handler: Box<dyn Handler<B>>,
}

pub struct Router<B = Body> {
    routes: Vec<Route<B>>,
}

impl Router {
    pub fn new() -> Self;
    pub fn route<S>(mut self, path: &str, handler: S) -> Self
    where S: Handler;

    pub async fn handle(&self, req: Request<B>) -> Response;
    // ─ path matching + method matching → dispatch
}
```

**Extractor 設計：**

```rust
// extract.rs (精簡版, 只做字串)
pub struct Path<T>(pub T);
impl<T: FromStr> FromRequest for Path<T> { /* parse from URI path segments */ }

pub struct Query<T>(pub T);
impl<T: FromStr> FromRequest for Query<T> { /* parse from URI query string */ }

pub struct Json<T>(pub T);
impl<T: DeserializeOwned> FromRequest for Json<T> { /* serde_json */ }
```

**IntoResponse：**

```rust
// into_response.rs
pub trait IntoResponse {
    fn into_response(self) -> Response<Body>;
}

impl IntoResponse for &'static str { /* 200 + text/plain */ }
impl IntoResponse for String { /* 200 + text/plain */ }
impl IntoResponse for Vec<u8> { /* 200 + application/octet-stream */ }
impl IntoResponse for StatusCode { /* 對應狀態碼 + 空 body */ }
impl<T: IntoResponse> IntoResponse for (StatusCode, T) { /* 自訂狀態碼 */ }
impl IntoResponse for Response<Body> { /* identity */ }
```

**serve 函數：**

```rust
// serve.rs
pub async fn serve(listener: TcpListener, router: Router) {
    loop {
        let (stream, _) = listener.accept().await.unwrap();
        let router = router.clone();
        spawn(async move {
            // 1. read Request  (parse HTTP from stream)
            // 2. router.handle(request) → Response
            // 3. write Response (serialize to stream)
        });
    }
}
```

HTTP 讀取策略：先 read 4KB 到 buffer，parse，若 body 未完整則繼續
read（根據 Content-Length），簡單但夠用。

### Step 3: xv8-tokio-compat 擴充

幾個小補強讓 framework 寫起來更順：

```rust
// sync/watch.rs — 仿 tokio::sync::watch
pub fn channel<T>(init: T) -> (Sender<T>, Receiver<T>);
impl Sender<T> { fn send(&self, val: T); fn modified(&self); }
impl Receiver<T>: Future<Output = T> { /* 收到新值時 Ready */ }

// sync/mpsc.rs — 仿 tokio::sync::mpsc (unbounded)
pub fn channel<T>(buffer: usize) -> (Sender<T>, Receiver<T>);
impl Sender<T> { fn send(&self, val: T) -> Result<()>; }
impl Receiver<T> { fn recv(&mut self) -> Recv<T>; }

// sync/notify.rs — 仿 tokio::sync::Notify
pub struct Notify { /* ... */ }
impl Notify {
    fn notified(&self) -> Notified<'_>;    // Future
    fn notify_one(&self);
    fn notify_waiters(&self);
}

// time.rs 擴充
pub fn timeout<F, T>(dur: Duration, future: F) -> Timeout<F>;
pub fn interval(period: Duration) -> Interval;

// macros.rs — 簡化版 select!
// 不用 proc macro, 用 macro_rules 實作簡單的 2-way select
macro_rules! select {
    ($($name:ident = $fut:expr => $handler:expr),+ $(,)?) => { ... };
}

// io.rs 擴充
pub async fn copy(mut reader, mut writer) -> Result<u64>;
pub fn split(stream) -> (ReadHalf, WriteHalf);
```

### Step 4: 測試更新

**`_axum.rs` 改寫：**

原本手動 read→parse→write HTTP 字串，改成用 `xv8-router`：

```rust
#[unsafe(no_mangle)]
fn main(_args: Args) {
    let rt = Runtime::new();
    rt.block_on(async {
        let app = Router::new()
            .route("/", get(|| async { "ok" }));
        let listener = TcpListener::bind(27002).await.unwrap();
        serve(listener, app).await;
    });
}
```

client 端不變（仍用 raw syscall），fork 模式不變。

**新增 `_httpd.rs` testbin：**

展示 path parameter + file response：

```rust
async fn serve_file(Path(name): Path<String>) -> Response<Body> {
    match std::fs::read_to_string(&name) {
        Ok(content) => Response::new(StatusCode::OK)
            .header("Content-Type", "text/plain")
            .body(content.into_bytes()),
        Err(_) => StatusCode::NOT_FOUND.into_response(),
    }
}
```

**新增 `_json.rs` testbin（選用）：**

若 serde_json 可編譯，展示 JSON extractor + response。

### 邊界情況與注意事項

| 項目 | 處理方式 |
|------|----------|
| HTTP/1.1 keep-alive | 不支援（每次請求後 close） |
| chunked encoding | 不解析（回傳 501） |
| 大 body > 16KB | 限制 16KB（user stack 上限） |
| 慢客戶端 (slow loris) | 不回處理，block 在 read |
| 並行請求 | 每次 accept 後 spawn（xv8 無 thread，只有 fork+exec） |
| Path 參數類型 | 只支援 `:param` 語法（仿 axum），不支援 `*` wildcard |
| Query 字串 | 複雜 parse 放 extractor 層，router 層只保留 raw string |

## 不做的功能（明確排除）

- ❌ WebSocket upgrade
- ❌ TLS/SSL
- ❌ HTTP/2
- ❌ Tower Service trait（直接用 Handler trait）
- ❌ Streaming body（chunked 或 SSE）
- ❌ CORS 中間件
- ❌ Router 巢狀 (`nest`)
- ❌ `serde` 序列化（除非 `serde_json` 能在 riscv64 編譯）
- ❌ `tower` / `tower-http` 中間件層

2. `xv8-tokio-compat` — watch, mpsc, Notify, timeout, select! (跟 1 平行)
