# v2.4 — xv8-user-std 基礎補缺

**目標：打通 Rust 生態的敲門磚**

---

## 這版做了什麼

### xv8-user-std 基礎補缺

- `std::net::Ipv4Addr` / `Ipv6Addr` / `IpAddr` / `SocketAddrV4` / `SocketAddrV6` — 完整位址型別（parse, display, constants, ToSocketAddrs）
- `std::io::Cursor<T>`（for `Vec<u8>` 及 `&[u8]`）— 記憶體讀寫 cursor
- `std::io::BufWriter<W>` — 緩衝寫入
- `std::io::copy()` — Reader→Writer 複製
- `std::ffi::OsString` — 除了 `OsStr` 的 owned 版本（Deref, From, AsRef, Borrow, ToOwned）
- `std::panic::catch_unwind()` / `AssertUnwindSafe` / `UnwindSafe` / `RefUnwindSafe`
- `Path::is_absolute()` / `is_relative()` / `starts_with()` / `ends_with()` 修復
- `PathBuf::push()` / `pop()` / `set_file_name()` / `with_extension()` 實作
- `Path::as_os_str()` 回傳 `&OsStr`（原為 `&str`）
- `std::env::temp_dir()` / `home_dir()` / `consts`（ARCH, FAMILY, OS 等）
- `std::fs::canonicalize()` / `remove_dir_all()`

### sbrk allocator 修復

- `dealloc` 實作：free list 依位址排序，插入時 coalesce 相鄰 block
- `alloc` first-fit 搜尋，大 block 可分割

### 其他修正

- `Ipv6Addr::to_ipv6_compatible()` / `to_ipv6_mapped()` 參數個數修復（10→8）
- `Ipv6Addr` Display 迭代器 `mut` 修復
- `IpnAddr`/`Ipv6Addr` 常數 `UNSPECIFIED`/`LOOPBACK`/`BROADCAST` 從 `const fn` 改為 `const` item
- `net.rs` 匯入 `alloc::vec::Vec` 補齊
