## epoll 核心功能

- `epoll_create1(flags)` → FD（建立 epoll instance）
- `epoll_ctl(epfd, op, fd, event)` — ADD（加入監聽）/ MOD（修改事件）/ DEL（移除）
- `epoll_wait(epfd, events, maxevents, timeout)` — 阻塞等待事件
- 支援事件：EPOLLIN, EPOLLOUT, EPOLLERR, EPOLLHUP, EPOLLET（邊緣觸發，基礎支援）
- TCP listener 和 stream 在 accept/connect/close 時通知 epoll instance
- `fd_readiness()` 實作於所有 FD 型別，epoll_wait 內部使用

## 測試結果

epoll_create1, epoll_ctl, epoll_wait QEMU 整合測試通過。

## Bugfix: fds_at offset 未重置

v4.4 開發中發現 file slot 重複使用時 `fds_at` offset 未被重置為 0，導致 eventfd2、memfd_create 等新建 FD 繼承前一個 slot 的 offset。已在 `sys_eventfd2()` 和 `sys_memfd_create()` 中修復（加入 `inner.offset = 0`）。
