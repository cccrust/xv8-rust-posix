# xv8rust v0.3

**目標：讓 `posix/tools` 的 135 個工具在 riscv64gc-unknown-none-elf 編譯成功。**

v0.3 是功能補完版本，擴充 `xv8-user-std` 各模組以滿足 POSIX 工具編譯需求。

## xv8-user-std 新增功能

### 執行期（`runtime.rs`，新增）
- `_start` entry point（呼叫 `main()` 後 `exit()`）
- `#[panic_handler]`（印出 panic 訊息後無窮迴圈）
- `#[global_allocator]`（基於 `sbrk` syscall）
- `#[lang = "start"]`（含 `Termination` trait、`safe_main` 橋接）

### `lib.rs`
- `pub use alloc::vec::Vec`、`pub use alloc::boxed::Box`
- 自定義 `vec!`、`format!` macro（因 compiler 不會 auto-import 跨 crate macro）
- 新模組：`char`、`iter`、`error`（皆 `pub use core::*`）
- Prelude 擴充：含 `Box`、`String`、`ToString`、`Vec`、`vec!`、`format!`、`println!` 等

### `io.rs`
- **Blanket impls**：`impl Read/Write/BufRead for Box<T>`、`impl Read/Write/BufRead for &mut T`
- **IsTerminal trait**：為 `Stdin/Stdout/Stderr` 及 Lock variants 實作
- **`Stdin::lines()`**：回傳 `Lines<StdinLock>`
- **`Stdin::is_terminal()`**：直接呼叫 `IsTerminal::is_terminal`
- **`impl Write for Stdin`**：寫入 fd 0
- **`Read::read_exact()`**：讀取完整 buf.len() bytes
- **`Error: impl std::error::Error`**：支援 `Box<dyn Error>` 的 `?` 轉換

### `path.rs`
- **`PathBuf: Deref<Target=Path>`**：自動解參照 `&PathBuf` → `&Path`
- **`Path::file_stem()`**：去除副檔名
- **`OsStr: AsRef<Path>`**：`join(entry.file_name())` 可用

### `ffi.rs`
- **`OsStr`** 完整實作：`from_str`、`to_string_lossy`、`as_encoded_bytes`、`Debug/PartialEq/Eq/Ord/AsRef<Path>`
- **`CString::as_ptr()`**、**`Default for CString`**

### `fs.rs`
- **`FileType` enum**：`RegularFile`、`Directory`、`Symlink`、`Other`
- **`Metadata::file_type()`**、**`uid()`**、**`gid()`**
- **`File::options()`**、**`File::seek()`**
- **`OpenOptions::create_new()`**
- **`fs::read()`**：讀取完整檔案為 `Vec<u8>`
- **`fs::read_link()`**：stub（回傳 `Unsupported`）
- **`read_to_string()`** fix：`File` 不需 `mut`

### `process.rs`
- **`process::id()`**：包裝 `xv8_libc::getpid`
- **`Command::stdin/stdout/stderr/envs`**
- **`Command::output()`** 回傳 `io::Result<Output>`（原為 `ExitStatus`）
- **`ChildStdout`**：實作 `Read`（stub）
- **`Output` struct**：含 `status`、`stdout`、`stderr`
- **`Child`**：stdout 改為 `Option<ChildStdout>`
- Stdio 新增 `From` 橋接：`File`、`ChildStdout`、`Stdin`、`Stdout`

### `time.rs`
- **`Instant`**：monotonic clock（stub，回傳 0）
- **`Duration::subsec_nanos()`**
- **`Duration::subsec_millis()`**

### `env.rs`
- `set_var()`、`remove_var()`（stub，無操作）

## 關鍵設計決策

1. **Macro 重複匯出**：Rust 編譯器不會對覆寫的 `std` crate auto-import `#[macro_export]` macro。所有 macro（`print!`、`vec!`、`format!`）必須手動 `pub use crate::...` 到 prelude 模組。

2. **`#[lang = "start"]`**：使用 `build-std` 時必須提供，否則 compiler 無法解析 `fn main()`。單元測試回報 `Termination` trait 未實作錯誤，可透過 `safe_main` 橋接模式處理。

3. **`str::as_encoded_bytes()` 在 `core` 不存在**：該方法屬於 `std::ffi::OsStr`。當 `DirEntry::file_name()` 回傳 `&OsStr`（含自訂 `as_encoded_bytes()`），`ls.rs` 可正確編譯。

4. **`OsStr` 是 unsized type**：使用 `#[repr(C)]` 搭配 transmute，`from_str()` 將 `&str` 轉為 `&OsStr`。

5. **`Vec<u8>` vs `Box<[u8]>`**：Path 內部使用 `Vec<u8>` 以簡化操作，PathBuf 同理。

## 已知限制

- **10 個工具因 `libc` crate 無法編譯**：需要為 riscv64 提供 `libc` 封裝或替代實作
- **`fs::read_link`、`process::spawn` 等回傳 `Unsupported`**：執行時期會失敗，需補 syscall
- **`SystemTime::now()`、`Instant::now()` 回傳 0**：需 `clock_gettime` syscall 支援
- **`hashbrown` 依賴**：HashMap 來自第三方 crate，可能與未來 `std` 版本略有差異
