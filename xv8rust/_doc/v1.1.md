# xv8rust v1.1

**目標：先做出可掛載 `tokio` / `axum` 的最小 async runtime / reactor 骨架，再用一個最小 HTTP server smoke test 驗證 xv8 上的 async 鏈路。**

這一版不以「完整 Tokio 相容」為目標，而是先把目前 `xv8-user-std` 已有的 fd、sync、time、net 能力串成一個可操作的 async 入口。

## 規劃重點

- 單執行緒 `block_on`
- 基本 `spawn` 與 `JoinHandle`
- `sleep` / timer future
- 最小 IO reactor，先支援 listener / stream 類場景
- 最小 axum smoke test，確認 route dispatch 與 TCP listener 能跑

## 目前狀態

- `xv8rust/xv8-async` 已新增，step 1 完成
- `xv8rust/xv8-axum-smoke` 已新增，host smoke test 已通過
- 目前只做到最小 executor / timer reactor，以及 host 版 axum smoke path
- 文件與 roadmap 已對齊到 `xv8rust/_doc/plan.md` 與 `_doc/todo3.md`

## 驗收方向

- `xv8rust` target build 通過
- 最小 async runtime 可在 xv8/QEMU 中跑起來
- axum smoke test 之後要補成 xv8/QEMU 版
