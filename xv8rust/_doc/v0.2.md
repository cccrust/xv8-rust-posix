# xv8rust v0.2

**目標：讓 xv8-libc 成為獨立 no_std crate，xv8-user-std 依賴 xv8-libc 而非 user crate，解除 riscv64gc-unknown-none-elf 編譯阻塞。**

v0.2 是架構重整版本，取消對 `user` crate（std-based, edition 2024）的依賴，改為只依賴 `xv8-libc`（no_std, 獨立 ecall wrapper）。

---

## xv8-libc 變更

### `raw.rs` 新增
- `Syscall::Chdir = 9`
- `pub fn chdir(path: *const u8) -> isize`
- `Stat` 增加 `#[derive(Default)]`

### `args.rs`（新增）
從 `user/src/args.rs` 移植，不依賴任何外部 crate，純 `core::arch::asm` 從 a0/a1 暫存器讀取 argc/argv：

```rust
pub struct Args {
    pub argc: usize,
    pub argv: *const *const u8,
}
impl Args {
    pub unsafe fn from_stack() -> Self { ... }
    pub fn get(&self, index: usize) -> Option<&'static [u8]>
    pub fn get_str(&self, index: usize) -> Option<&'static str>
    pub fn args(&self) -> ArgsIter
}
```

### `lib.rs` 新增
- `pub mod args`
- `re-export: chdir`
- `OpenFlag` struct：
  - `READ_ONLY = 0x000`
  - `WRITE_ONLY = 0x001`
  - `READ_WRITE = 0x002`
  - `CREATE = 0x040`
  - `EXCLUSIVE = 0x080`
  - `TRUNCATE = 0x200`
  - `APPEND = 0x400`

## xv8-user-std 變更

### Cargo.toml
```toml
# 改為依賴 xv8-libc（no_std）
# 移除 user crate 依賴
[dependencies]
xv8-libc = { path = "../xv8-libc" }
```

### `io.rs`（完全重寫）
- 自定義 `Read`, `Write`, `BufRead`, `Seek` traits（不依賴 `core::io`，因為 core 無 io）
- 自定義 `Error`, `ErrorKind`, `Result<T>` 類型
- `Stdin`, `Stdout`, `Stderr` + Lock variants
- `BufReader<R>`, `Lines<B>`, `Bytes<R>`, `Chain<T,U>`, `Take<T>`
- 所有 syscall 改為呼叫 `xv8_libc::{read, write}`

### `env.rs`（重寫）
- `EnvArgs` 使用 `xv8_libc::args::Args` 取代 `user::syscall::Args`
- `current_dir()` → stub（kernel 無 getcwd syscall）
- `set_current_dir()` → 使用 `xv8_libc::chdir`

### `fs.rs`（重寫）
- `File` 內部使用 `usize` fd，非 `user::syscall::Fd`
- 改用 `xv8_libc::{open, close, read, write, fstat, OpenFlag, Stat}`
- 移除 `user::kernel::abi::{OpenFlag, Stat, SysError}` 依賴

### `process.rs`（重寫）
- `exit()` 改用 `xv8_libc::exit`
- Command/Child/Stdio 保持 stub

### 其餘模組
- `path.rs`：小幅修正（lifecycle, `exists()` 不用 unsafe）
- `time.rs`：Duration + SystemTime stub
- `thread.rs`：sleep stub
- `ffi.rs`：CStr, CString
- `os/unix/fs.rs`：MetadataExt, PermissionsExt
