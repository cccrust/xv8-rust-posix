# xv8rust v0.6

**目標：把 `posix => xv8rust => xv8` 串成一條可重複驗證的完整鏈路，並確認 `posix/tools/` 全數可在 xv8 上編譯與執行。**

這版不是再補單一 API，而是把前一版完成的 runtime / syscall / 相容層工作，落到可驗證的整體流程上。

---

## 這版做了什麼

### 根目錄驗證入口
- 新增 `test.sh`，一次跑完三段驗證：
  1. `posix` host tests
  2. `posix` xv8 target build
  3. `xv8rust` xv8 target build
  4. `xv8/test.sh` kernel integration test

### xv8 target 入口整理
- 加入 `.cargo/config.toml`
- 加入 `.cargo/rustc-wrapper.sh`
- 針對 `riscv64gc-unknown-none-elf` 的 `src/bin/*` 自動注入 `no_main` / `no_mangle`
- 讓 `posix/tools` 不必逐一修改 135 個 bin 檔，就能在 xv8 target 上完成連結

### 測試修正
- 修正 `posix/tools/tests/basic.rs` 的 `tool_path()`，避免誤抓到系統上的 `mailx`
- 修正 `posix/tools/src/bin/ipcrm.rs` 的 `shmctl` / `semctl` 型別，讓 target build 穩定通過

---

## 結論

這版把前面分段完成的工作整合成完整系統：

- `posix/tools` 可以在 host 上測試
- `posix/tools` 可以在 xv8 target 上編譯
- `xv8rust` 可以提供必要的 std / libc 相容支援
- `xv8` 可以完成整體整合測試

網路相關功能仍保留未測，因為這個環境不以 QEMU 網路模擬為主。
