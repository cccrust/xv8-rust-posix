# xv8rust v0.1

**目標：讓最多 binary 能編譯，佔大多數的文字處理工具（cat, head, tail, grep, sort, uniq, tr, ...）零修改直接編譯到 xv8。**

這是精簡中的精簡。只實作 io 和 path（文字處理工具的核心需求），env 只實作 `args()`。其餘全部 stub，讓編譯通過，執行時失敗也接受。

---

## 產出

- `xv8rust/Cargo.toml` — workspace，成員 `xv8-libc`、`xv8-std-overlay`
- `xv8_libc/` — syscall wrapper crate
- `xv8rust-overlay/` — std trait 實作 crate（同時作為 `std` alias）

---

## 架構

```
xv8rust/
├── Cargo.toml              # workspace
├── xv8-libc/               # 成員1：syscall wrapper（C-like API）
│   ├── Cargo.toml
│   └── src/lib.rs
└── xv8-std-overlay/        # 成員2：std 實作
    ├── Cargo.toml

        ├── lib.rs
        ├── io.rs           # Read, Write, BufRead（核心）
        ├── path.rs         # Path, PathBuf
        └── env.rs          # args() only
```

## xv8-libc

**只實作這幾個符號：**

```rust
// io
pub fn read(fd: usize, buf: &mut [u8]) -> isize
pub fn write(fd: usize, buf: &[u8]) -> isize
// fs
pub fn open(path: *const u8, flags: u32, mode: u32) -> isize  // CStr 作 *const u8
pub fn close(fd: usize) -> isize
pub fn lseek(fd: usize, offset: i64, whence: i32) -> isize
pub fn fstat(fd: usize, stat: *mut Stat) -> isize
pub fn readdir(fd: usize) -> isize
// proc
pub fn exit(code: i32) -> !
pub fn getpid() -> usize
// env（exec 參數儲存）
pub fn getcmdline() -> *mut *mut u8  // 回傳 argv 指標
```

其餘全部 `pub fn stub() -> isize { -1 }` 或 `pub fn stub_never() -> ! { loop {} }`。

**依賴：** `extern crate user`（指向 `xv8/user`，裡面有 syscall 函式）。這是關鍵——`xv8-libc` 不需要自己定義 syscall，它只需要轉接 `user` crate 已經實作的 syscall wrappers。

## xv8-std-overlay

### `lib.rs`

```rust
#![no_std]
extern crate alloc;

pub mod io;
pub mod path;
pub mod env;

pub use io::*;
pub use path::*;
pub use env::*;

// 沒有被任何 binary 用到的模組，宣告為空模組讓編譯通過
pub mod collections {
    extern crate alloc;
    pub use alloc::collections::*;
}
pub mod process { pub use ::process::exit; }  // stub：實際沒有實作 Command
pub mod time { pub use ::time::Duration; }     // stub：只有 Duration，無 SystemTime
pub mod thread { pub fn sleep(_: time::Duration) {} }  // stub
pub mod ffi { /* 只宣告 empty，讓用到 CStr/CString 的程式碼能編譯 */ }
pub mod fs { /* 實作在 io.rs */ }
pub mod envvars { pub fn vars() -> EnvVars { EnvVars { i: 0 } } pub struct EnvVars { i: usize } impl Iterator for EnvVars { type Item = (String, String); fn next(&mut self) -> Option<Self::Item> { None } } }
```

**重要：** 由於 `std` 是編譯器內建的，無法在 `Cargo.toml` 裡直接 `depend on "std"`。實作方式是在 `xv8-std-overlay/Cargo.toml` 裡不宣告任何 `std` dependency，而是在每個 module 裡用 `pub use ::std::...` 的方式轉接。這需要整個 crate 以 `#![no_std]` 模式編譯（不依賴內建 std）。

### `io.rs`（核心）

```rust
use core::fmt;

pub struct Stdin;
pub struct Stdout;
pub struct Stderr;

static mut STDIN_BUF: [u8; 1024] = [0; 1024];
static mut STDIN_POS: usize = 0;
static mut STDIN_LEN: usize = 0;

impl Stdin {
    pub fn read_line(&self, buf: &mut String) -> io::Result<usize> {
        // 從 user syscall 讀取一行
        let mut line = [0u8; 256];
        let n = unsafe { xv8_libc::read(0, &mut line) };
        if n <= 0 { return Ok(0); }
        let s = core::str::from_utf8(&line[..n as usize]).unwrap_or("");
        buf.push_str(s);
        Ok(n as usize)
    }
}

impl io::Read for Stdin {
    fn read(&mut self, buf: &mut [u8]) -> io::Result<usize> {
        let n = unsafe { xv8_libc::read(0, buf) };
        if n < 0 { Err(io::Error::last_os_error()) } else { Ok(n as usize) }
    }
}

impl io::Write for Stdout {
    fn write(&mut self, buf: &[u8]) -> io::Result<usize> {
        let n = unsafe { xv8_libc::write(1, buf) };
        if n < 0 { Err(io::Error::last_os_error()) } else { Ok(n as usize) }
    }
    fn flush(&mut self) -> io::Result<()> { Ok(()) }
}

impl io::Write for Stderr {
    fn write(&mut self, buf: &[u8]) -> io::Result<usize> {
        let n = unsafe { xv8_libc::write(2, buf) };
        if n < 0 { Err(io::Error::last_os_error()) } else { Ok(n as usize) }
    }
    fn flush(&mut self) -> io::Result<()> { Ok(()) }
}

impl fmt::Write for Stdout {
    fn write_str(&mut self, s: &str) -> fmt::Result {
        self.write_all(s.as_bytes()).map_err(|_| fmt::Error)
    }
}

impl io::BufRead for Stdin {
    fn fill_buf(&mut self) -> io::Result<&[u8]> {
        // 用靜態緩衝區，每次 fill_buf 重新填充
        unsafe {
            STDIN_POS = 0;
            let n = xv8_libc::read(0, &mut STDIN_BUF);
            if n <= 0 {
                STDIN_LEN = 0;
                Ok(&[])
            } else {
                STDIN_LEN = n as usize;
                Ok(&STDIN_BUF[..STDIN_LEN])
            }
        }
    }
    fn consume(&mut self, amt: usize) {
        unsafe { STDIN_POS += amt; }
    }
}

impl io::Read for &Path {
    fn read(&mut self, buf: &mut [u8]) -> io::Result<usize> { ... }
}
```

### `path.rs`

只實作 `posix/tools/` 實際用到的 API：

```rust
pub struct Path { inner: [u8] }
pub struct PathBuf { vec: Vec<u8> }

impl Path {
    pub fn new(s: &[u8]) -> &Path { Path { inner: *s } }
    pub fn to_str(&self) -> Option<&str> {
        core::str::from_utf8(&self.inner).ok()
    }
    pub fn file_name(&self) -> Option<&Path> {
        let s = self.to_str()?;
        let i = s.rfind('/').map(|i| i + 1).unwrap_or(0);
        Some(Path::new(s[i..].as_bytes()))
    }
    pub fn is_absolute(&self) -> bool { false }  // stub
    pub fn ends_with(&self, _: &Path) -> bool { false }  // stub
}

impl PathBuf {
    pub fn from(s: &[u8]) -> Self { PathBuf { vec: Vec::from(s) } }
    pub fn push(&mut self, _: &Path) {}  // stub
    pub fn to_path_buf(&self) -> Path { Path { inner: self.vec.as_slice().try_into().unwrap() } }
    pub fn as_path(&self) -> &Path { Path::new(&self.vec) }
}

impl fmt::Display for Path {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "{}", self.to_str().unwrap_or("?"))
    }
}
```

### `env.rs`

```rust
pub struct Args { argc: usize, argv: *mut *mut u8 }

impl Args {
    pub fn new() -> Self {
        let argv = unsafe { xv8_libc::getcmdline() };
        let argc = unsafe { core::ptr::read(argv.cast::<usize>().offset(0)) };
        Args { argc, argv }
    }
}

impl Iterator for Args {
    type Item = String;
    fn next(&mut self) -> Option<String> {
        if self.argc == 0 { return None; }
        let ptr = unsafe { core::ptr::read(self.argv as *const *mut u8) };
        if ptr.is_null() { return None; }
        let len = unsafe { core::ffi::strlen(ptr) };
        let slice = unsafe { core::slice::from_raw_parts(ptr, len) };
        self.argv = unsafe { self.argv.add(1) };
        self.argc -= 1;
        String::from_utf8(slice.to_vec()).ok()
    }
}

pub fn args() -> Args { Args::new() }
pub fn vars() -> EmptyEnvVars { EmptyEnvVars }
pub struct EmptyEnvVars;
impl Iterator for EmptyEnvVars { type Item = (String, String); fn next(&mut self) -> Option<Self::Item> { None } }
```

## 與 posix/tools 的整合

在 `posix/tools/Cargo.toml` 中使用 `cfg` 根據 target 切換 dependency：

```toml
[target.riscv64gc-unknown-none-elf.dependencies]
std = { package = "xv8-std-overlay" }
```

這讓 `posix/tools/` 在編譯到 xv8 時，把 `use std::io::Read` 解析到 `xv8rust_overlay::io::Read`。

但有個問題：crates.io 上的 third-party crates（如 `regex`）仍然依賴 `std`，編譯到 xv8 時會找不到內建 `std`。這是 v0.1 的限制——**只有直接使用 `std` 的程式碼能編譯**，第三方 `std` crates 無法使用。

## v0.1 涵蓋的 binary

以下 binary 應該能在 v0.1 下編譯（全部 ~20 個文字處理工具）：

`cat`, `head`, `tail`, `grep`, `sed`, `sort`, `uniq`, `tr`, `tee`, `wc`, `cut`, `od`, `cmp`, `expand`, `unexpand`, `fmt`, `nl`, `fold`, `paste`, `strings`

`ls` 需要額外的 `std::fs`（read_dir）和 `std::os::unix::fs`（MetadataExt）——屬於 v0.2。

`touch` 需要 `std::time::SystemTime` 和 `utimes` syscall——屬於 v0.2。

`sh`、`xargs` 需要 `std::process::Command::spawn`（fork/exec）——屬於 v0.3。

`sleep` 需要 `std::thread::sleep`——stub 在 v0.1 可以編譯，但執行時馬上回傳。

---

## v0.1 不做的事

- `std::fs`（read_to_string、read_dir、File、OpenOptions、Metadata）
- `std::process::Command`、`Stdio`、`Child`
- `std::env::vars()`
- `std::env::current_dir()`（chdir syscall）
- `std::time::SystemTime::now()`（時鐘 syscall）
- `std::thread::spawn`
- `std::os::unix::fs::{MetadataExt, PermissionsExt}`
- `std::ffi::{CStr, CString}`（指標包裝）
- `std::collections::HashMap`
- 所有網路功能

## 驗收標準

1. `xv8-libc` crate 在 `riscv64gc-unknown-none-elf` target 編譯成功
