# xv8rust v1.0

**目標：將 crossterm 供應商化放入 xv8rust、補上 riscv64 terminal backend、修正 heredoc，讓 posix shell + vi/vim 在 host 上可正常運作，riscv64 則可跳過 crossterm 編譯。**

這版從「讓工具能跨平台編譯」進入「讓終端機工具在 host 完整可用」的階段，也把 crossterm 的整個相依性鏈鎖定在專案內。

---

## 這版做了什麼

### crossterm 供應商化

- 從 crates.io 下載 crossterm 0.29.0 原始碼，放入 `xv8rust/crossterm/`
- 建立 `xv8rust/crossterm/Cargo.toml`，依賴：
  - `spin`（通用，取代 parking_lot on riscv64）
  - `parking_lot`（unix only，非 riscv64）
  - `xv8-libc`（riscv64 only）
  - `libc`、`rustix`、`mio`、`signal-hook`、`signal-hook-mio`（unix only）
- 預設 features：`["bracketed-paste", "libc", "events"]`（libc 避免走 rustix 的 AsFd trait 路徑）
- `posix/tools/Cargo.toml` 的 crossterm dep 改指向 `path = "../../xv8rust/crossterm"`

### riscv64 terminal backend

- 新增 `xv8rust/crossterm/src/terminal/sys/riscv64.rs`：
  - `enable_raw_mode()` / `disable_raw_mode()`：透過 `xv8_libc::ioctl(fd, CONSOLE_SET_RAW, 1/0)`
  - `window_size()` / `size()`：回傳預設 80×24
  - 狀態記錄在 `spin::Mutex<bool>` 中
- 修改 `terminal/sys.rs`：`cfg(target_arch = "riscv64")` 時 include mod riscv64
- 修改 `terminal.rs`：`is_raw_mode_enabled()` 增加 `cfg(any(unix, target_arch = "riscv64"))` 分支

### spin 取代 parking_lot

- `style/types/colored.rs`：`parking_lot::Once` → `spin::Once`，以 `cfg(target_arch = "riscv64")` 條件切換
- `spin` 是 no_std compatible，riscv64 用，unix 仍用 parking_lot

### xv8-libc 新增 syscall wrappers

- `raw.rs`：新增 `Syscall::Ioctl = 23`、`Tcgetattr = 60`、`Tcsetattr = 61`
- 新增 `ioctl(fd, cmd, arg)`、`tcgetattr(fd, termios)`、`tcsetattr(fd, opt, termios)` wrapper
- `lib.rs`：匯出 `ioctl`、`tcgetattr`、`tcsetattr`、`IoctlCmd`（含 `CONSOLE_SET_RAW = 1`）

### heredoc 修正（posix shell）

- `sh.rs` 的 `collect_complete_lines`：累積 heredoc body 直到分隔行，unquoted delimiter 在 exec 時才做變數展開
- tokenizer：quoted heredoc delimiter `<< "EOF"` 補回漏掉的結尾引號字元
- 新增 `pending_heredocs: HashMap<String, (String, bool)>` 到 `ShellContext`
- `parse_redirects` 檢查 `ctx.pending_heredocs`，解決管線中 heredoc 的內容遺失問題

### crossterm 可選化

- `posix/tools/Cargo.toml`：加入 features `default = ["crossterm"]` + `crossterm = ["dep:crossterm"]`
- vi/vim bin 加上 `required-features = ["crossterm"]`
- `test.sh` riscv64 build 使用 `--no-default-features` 跳過 crossterm

## 關鍵設計決策

| 決策 | 理由 |
|------|------|
| 全部平台走同一個 vendored crossterm | 避免 host 用 crates.io、riscv64 用 local 的雙重維護 |
| `spin` 取代 `parking_lot` 用 cfg gate 而非 wrapper crate | `spin` 原生 no_std，不需要再寫一層 shim |
| `cfg(target_arch = "riscv64")` 而非 `cfg(unix)` | riscv64gc-unknown-none-elf 既不設 unix 也不設 windows，必須明確指定 |
| crossterm default 啟用 `libc` feature | 避免走 rustix 的 `AsFd` trait（與 std::os::fd 不相容） |
| vi/vim 設 `required-features = ["crossterm"]` | riscv64 用 `--no-default-features` 跳過，不用修改 vi/vim 原始碼 |
| 使用 ioctl `CONSOLE_SET_RAW` 而非 tcsetattr | xv8 kernel 的 raw mode 是簡單 boolean toggle，不需完整 termios |

## 限制

- crossterm 未實際對 riscv64 編譯驗證（`xv8-user-std` 不提供完整 std，無法編譯 terminal 工具）
- riscv64 terminal backend 未在 QEMU 中測試（需要 xv8 使用者程式支援 std 環境）
- `tcgetattr`/`tcsetattr` syscall wrappers 存在但未被 crossterm backend 使用
