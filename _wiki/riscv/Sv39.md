# Sv39 — RISC-V 分頁機制

Sv39 是 RISC-V 的 39 位元虛擬位址分頁機制，xv8 使用它來實現虛擬記憶體。

## 虛擬位址結構

```
  63    39    30    21    12     0
┌──────┬──────┬──────┬──────┬──────┐
│ EXT  │ PPN2 │ PPN1 │ PPN0 │ Off  │
└──────┴──────┴──────┴──────┴──────┘
   25     9     9     9    12   bits
```

- **EXT**：符號擴展（bit 38 複製到 63-39）
- **PPN2/PPN1/PPN0**：三層頁表索引（各 9 bits）
- **Off**：頁內偏移（12 bits，4KB 頁）

最大虛擬位址：`2^38 - 1 = 256GB 用戶空間`

## 頁表結構

Sv39 使用三層頁表（512 × 512 × 512 PTE）：

```rust
// 每層 512 個條目
pub const PXMASK: usize = 0x1FF;  // 9 bits

// 從虛擬位址提取第 level 層索引
pub const fn px(level: usize, va: usize) -> usize {
    (va >> (12 + 9 * level)) & PXMASK
}
```

## 頁表條目（PTE）結構

```
  63    54    10     0
┌──────┬──────┬──────┐
│ PPN  │flags │  V   │
└──────┴──────┴──────┘
   44    10    bits
```

- **PPN**：實體頁號（44 bits → 16TB PA 空間）
- **flags**：權限標誌（10 bits）
- **V**：有效位

## PTE 標誌

```rust
pub const PTE_V: usize = 1 << 0;  // Valid
pub const PTE_R: usize = 1 << 1;  // Readable
pub const PTE_W: usize = 1 << 2;  // Writable
pub const PTE_X: usize = 1 << 3;  // Executable
pub const PTE_U: usize = 1 << 4;  // User accessible
pub const PTE_COW: usize = 1 << 8; // Copy-On-Write
```

## 位址轉譯流程

```
虛擬位址 VA[38:0]
       │
       ├─ VA[38:30] → PPN2 索引 → Level 2 頁表
       │                     │
       │                     ├─ PPN2 → Level 3 頁表
       │                     │        │
       │                     │        ├─ VA[29:21] → PPN1 索引 → Level 2 頁表
       │                     │        │              │
       │                     │        │              ├─ PPN1 → Level 1 頁表
       │                     │        │              │        │
       │                     │        │              │        ├─ VA[20:12] → PPN0 索引 → Level 1 頁表
       │                     │        │              │        │              │
       │                     │        │              │        │              └─ PPN0 → 實體頁 Frame
       │                     │        │              │        │                          │
       │                     │        │              │        │                          └─ VA[11:0] + Frame PA
       │                     │        │              │        │
       │                     │        │              │        └─ 輸出 Level 1 PTE
       │                     │        │              │
       │                     │        │              └─ 輸出 Level 2 PTE
       │                     │        │
       │                     │        └─ 輸出 Level 3 PTE
       │                     │
       │                     └─ 輸出 Root PTE
       │
       └─ 組成最終實體位址
```

## 頁表遍歷

```rust
unsafe fn walk_raw(
    mut pagetable: NonNull<RawPageTable>,
    va: VA,
    alloc: bool,
) -> Result<*mut PageTableEntry, VmError> {
    for level in (1..=2).rev() {  // 從 PPN2 到 PPN0
        let pte = pagetable.as_mut().get_mut(va.px(level));

        if pte.is_v() {
            // 下一層頁表存在
            pagetable = NonNull::new(pte.as_pa().as_mut_ptr()).unwrap();
        } else {
            if !alloc { return Err(VmError::InvalidPage); }
            // 分配新頁表
            pagetable = RawPageTable::try_new()?;
            *pte = PA::from(pagetable.as_ptr() as usize).as_pte() | PTE_V;
        }
    }
    Ok(pagetable.as_mut().get_mut(va.px(0)).unwrap())
}
```

## 映射範例

```rust
// 將虛擬位址 va 映射到實體位址 pa
kvmmap(va, pa, size, PTE_R | PTE_W | PTE_X);

fn kvmmap(&mut self, va: VA, pa: PA, size: usize, perm: usize) {
    self.0.map_pages(va, pa, size, perm).unwrap();
}
```

## 使用者/核心頁表隔離

```rust
// 核心頁表
pub struct Kvm(PageTable);

// 用戶頁表
pub struct Uvm(pub PageTable);
```

## 為何 Sv39？

| 特性 | Sv39 | x86 PAE | x86-64 |
|------|------|---------|--------|
| VA 位元 | 39 | 36 | 48 |
| 映射空間 | 512GB | 64GB | 256TB |
| 頁表層數 | 3 | 2 | 4 |
| 頁面大小 | 4KB | 4KB | 4KB/2MB/1GB |

Sv39 提供良好的效能/複雜度平衡。

## TLB

分頁硬體有 TLB（Translation Lookaside Buffer）快取。最近的翻譯結果會被緩存。

```rust
// 刷新 TLB
pub unsafe fn sfence() {
    asm!("sfence.vma zero, zero");
}
```

## 與 x86 的比較

| RISC-V Sv39 | x86 | 說明 |
|-------------|-----|------|
| satp | CR3 | 頁表根目錄暫存器 |
| sfence.vma | INVLPG | TLB 失效 |
| PTE_U | U/S bit | 用戶/核心權限 |
| PTE_X | XD bit | 禁用執行（可選）|
