# v0.5 - Process & Terminal Syscalls

Date: 2026-05-31

## New Syscalls (8 added, total 62)

| Num | Name | Description |
|-----|------|-------------|
| 54 | dup2 | Duplicate file descriptor to specific number |
| 55 | getppid | Get parent process ID |
| 56 | setuid | Set real user ID |
| 57 | setgid | Set real group ID |
| 58 | getpgid | Get process group ID |
| 59 | isatty | Check if file descriptor is a terminal |
| 60 | tcgetattr | Get terminal attributes |
| 61 | tcsetattr | Set terminal attributes |

## Changes

### kernel/src/proc.rs
- Added `uid: u32` and `gid: u32` fields to `ProcData`
- Added `pgrp: Pid` field for process group tracking
- Fixed `fork()` to properly inherit parent process group
- Fixed `user_init()` to set initial pgrp for init process

### kernel/src/param.rs
- Changed `NOFILE` from 16 to 256

### kernel/src/syscall.rs
- Added syscall numbers 54-61 to `Syscall` enum
- Added match arms for new syscalls
- Added TryFrom cases for new syscall numbers

### kernel/src/sysfile.rs
- Implemented `sys_dup2`: duplicates file descriptor to specific number, closes existing fd at target if different

### kernel/src/sysproc.rs
- Implemented `sys_getppid`: returns parent pid from PROC_TABLE.parents array
- Implemented `sys_setuid`: sets process uid in ProcData
- Implemented `sys_setgid`: sets process gid in ProcData
- Implemented `sys_getpgid`: returns pgrp for specified pid (0 = current process), fixed to handle current pid lookup
- Implemented `sys_isatty`: returns 1 if fd is console device, 0 otherwise
- Implemented `sys_tcgetattr` and `sys_tcsetattr`: stubs returning 0 (success)

### user/src/syscall.rs
- Added user-space wrappers for all new syscalls
- Added `Fd::from_raw()` method for creating Fd from raw number

## Testing
- All 8 tests pass: fs, pipe, proc, fd, sbrk, cow, net, syscall
