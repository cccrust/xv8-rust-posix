# v5.2 — cgroups v2 (Control Groups) on xv8

Date: 2026-06-08

從 v5.1（Namespaces）到 v5.2，xv8 新增了 cgroups v2 支援，提供 CPU、記憶體、PIDs 等資源限制與監控的基礎架構。

---

## v5.2 重點：cgroups v2 資源控制

### 架構

```
使用者空間 (/dev/cgroup 裝置)
    ↓ write("create mygroup") / read() → stats
xv8 CgroupTree (kernel)
    ├── root  cgroup (id=0)
    │   ├── cpu: max=0(無限制) period=100000
    │   ├── memory: max=0
    │   └── pids: max=0
    └── testgroup (id=1)
        ├── cpu: max=50000 period=100000
        ├── memory: max=1048576
        └── pids: max=10
```

### 設計決策

- **裝置檔案介面**（非 cgroupfs）— xv8 無 VFS 層，因此使用 `/dev/cgroup` 字元裝置 (major=2) 搭配文字協定，不需要新 syscall
- **CgroupTree 使用 OnceLock<SpinLock<...>>** — 與 TCP/UDP table 相同的全域鎖定模式
- **文字指令協定** — `write()` 發送指令（create/attach/cpu.max/memory.max/pids.max），`read()` 取得統計
- **三種控制器**：CPU (quota/period)、Memory (max bytes)、PIDs (max processes)
- **Process 追蹤** — 支援 attach process 到指定 cgroup

### 核心新增

| 檔案 | 變更 |
|------|------|
| `kernel/src/cgroup.rs` | **新增** — CgroupTree、控制器、裝置 read/write |
| `kernel/src/lib.rs` | 加入 `mod cgroup;` + 開機 init 呼叫 |
| `kernel/src/file.rs` | 新增 `CGROUP_DEV = 2` 常數，read/write dispatch |
| `kernel/src/abi.rs` | 匯出 `CGROUP_DEV` 給使用者空間 |
| `user/bin/init.rs` | 開機時 `mknod("cgroup", CGROUP_DEV, 0)` |

### 裝置指令協定

```
write(fd, "create <name>\n")         — 建立新 cgroup
write(fd, "attach <pid> <name>\n")   — 將 process 加入 cgroup
write(fd, "cpu.max <max> <period> <name>\n")  — 設定 CPU 上限
write(fd, "memory.max <max> <name>\n")        — 設定記憶體上限
write(fd, "pids.max <max> <name>\n")          — 設定 process 數上限
read(fd, buf, len)  → 統計文字（所有 cgroup 的狀態）
```
