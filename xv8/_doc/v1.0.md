# v1.0 - POSIX Tools on xv8

Date: 2026-06-01

從 v0.1（xv6-like RISC-V kernel）到 v1.0，xv8 已成長為能執行 138 個 POSIX 工具、213 個測試全部通過的完整作業系統。

---

## v1.0 里程碑：POSIX 工具鏈完整落地

v1.0 的核心目標是把 `posix/tools/`（138 個由 Rust std 編寫的 POSIX 命令）完整移植到 xv8 上執行。這需要在三個層面同時完成：

### 1. xv8 kernel — 系統呼叫完備化

從 v0.1 的 30+ 個基本 syscall，成長到 **105 個 syscall dispatch arms**，涵蓋：

- 行程管理：fork, exec, wait, exit, getpid, getppid, setuid, setgid, getuid, getgid, setpgid, getpgid, setsid, getsid, kill, killpg
- 檔案系統：open, close, read, write, lseek, fstat, mkdir, mknod, unlink, link, rename, chmod, fchmod, chown, fchown, access, symlink, readlink, truncate, ftruncate, stat, mkfifo, pipe, pipe2, dup, dup2
- 記憶體：sbrk, mmap, munmap, mprotect, getpagesize
- 環境變數：getenv, setenv, unsetenv, clearenv
- 網路：socket, bind, connect, listen, accept, send, recv
- 終端機：isatty, ioctl, tcgetattr, tcsetattr, ttyname
- 時間：sleep, uptime, time, nanosleep, clock_gettime
- 其他：umask, getpid, getppid, getuid, geteuid, getgid, getegid, getpgid, getpgrp, setpgid, setpgrp, setsid, getsid, getresuid, getresgid, setresuid, setresgid, getgroups, setgroups, initgroups, pathconf, fpathconf, sysconf, confstr

#### 關鍵修正：Inode::stat() 回傳 mode=0

**檔案**: `xv8/kernel/src/fs.rs:603`

**問題**: `DiskInode` 沒有 `mode` 欄位 → `inner.mode` 永遠為 0 → `Inode::stat()` 回傳 mode=0 → overlay 的 `is_dir()` 對所有檔案回傳 false → `ls` 把所有目錄當檔案顯示，權限欄位顯示 `?---------`

**修正**: 在 `stat()` 中根據 `inner.r#type` 計算 mode：
- `Directory` → `0o40755`（drwxr-xr-x）
- `File` → `0o100644`（-rw-r--r--）
- `Device` → `0o20666`（crw-rw-rw-）
- `SymLink` → `0o120777`（lrwxrwxrwx）
- `Fifo` → `0o10666`（prw-rw-rw-）

#### Stat 結構體對齊

kernel `Stat` 與 xv8-libc `Stat` 皆為 `#[repr(C)]`，透過 raw byte copy 在 `sys_fstat` 中傳遞，確保欄位佈局一致。

### 2. xv8-libc — 系統呼叫包裝層

**位置**: `xv8rust/xv8-libc/`

提供 `no_std` 的 RISC-V ecall 包裝，總計 **45+ 個 wrapper functions**：

- 基礎 I/O：read, write, open, close, lseek
- 行程：fork, exec, exit, wait, getpid, kill
- 檔案操作：mkdir, unlink, link, rename, chmod, fchmod, chown, fchown, access, symlink, readlink, truncate, ftruncate
- 描述子：dup, dup2, pipe, isatty
- 環境變數：getenv, setenv, unsetenv, clearenv
- 記憶體：sbrk, mmap, munmap, mprotect
- 時間：sleep, uptime, time, nanosleep
- 其他：chdir, fstat, getuid, getgid, umask

**位置**: `xv8rust/xv8-user-std/`

在 `no_std` + `alloc` 環境下提供 `std` trait 實作，讓 `posix/tools/` 的 138 個 POSIX 工具無須修改即可編譯。

## xv8 Kernel 架構

### 系統核心

| 元件 | 說明 |
|------|------|
| Boot | 0x80000000 入口，machine-mode 啟動，supervisor-mode 初始化 |
| 記憶體管理 | Buddy allocator + Sv39 分頁，lazy allocation, COW fork |
| 行程管理 | 64 個行程 slots，round-robin 排程，sleep/wakeup，process groups |
| 檔案系統 | Log-structured with write-ahead logging，inode-based，目錄條目 14 bytes |
| 網路 | Ethernet, ARP, IPv4, UDP, DHCP, loopback |
| VirtIO | Block device (disk) 與 network driver |
| 控制臺 | UART serial console，支援 RAW/canonical mode |
| Shell | Line editor with history，管線、重導向、背景作業 |

### 核心模組

```
kernel/src/
├── main.rs          # 二進位入口
├── lib.rs           # kernel library & main()
├── entry.rs         # 開機入口
├── start.rs         # machine mode 啟動
├── proc.rs          # 行程管理與排程
├── vm.rs            # 虛擬記憶體 (Sv39)
├── kalloc.rs        # 實體記憶體配置
├── fs.rs            # 檔案系統 (inode, directory, stat)
├── file.rs          # 檔案描述子抽象層
├── syscall.rs       # Syscall 分派器 (105 arms)
├── sysproc.rs       # 行程相關 syscall 實作
├── sysfile.rs       # 檔案相關 syscall 實作
├── trap.rs          # Trap 處理
├── pipe.rs          # Pipe 實作
├── exec.rs          # ELF exec 實作
├── console.rs       # 控制臺驅動
├── virtio_disk.rs   # VirtIO block 驅動
├── net/             # 網路協定棧
│   ├── eth.rs, arp.rs, ipv4.rs, icmp.rs
│   ├── udp.rs, dhcp.rs, route.rs
│   └── loopback.rs
└── ...
```

## 結論

v1.0 是 xv8 從「xv6-like RISC-V kernel」蛻變為「能執行 138 個 POSIX 工具的實用作業系統」的里程碑版本。

關鍵技術突破：
1. **xv8rust overlay**：在 `no_std` 環境下提供完整的 Rust `std` trait 實作，讓 POSIX 工具不必修改即可編譯
2. **xv8-libc**：100+ RISC-V ecall 封裝，作為 kernel 與 userspace 之間的薄層
3. **Stat 相容性修正**：從檔案類型推導 mode，讓 `ls -la` 顯示正確的 `drwxr-xr-x` 權限
4. **Unlink/Rename/Chmod 等 syscall 包裝**：補完檔案操作所需的核心系統呼叫，讓 `rm`、`mv`、`chmod` 真實可用
