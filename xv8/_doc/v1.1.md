# v1.1 — DNS tool on xv8 (first network application)

Date: 2026-06-01

從 v1.0（POSIX 工具鏈完整落地）到 v1.1，xv8 完成了第一條從使用者程式到網際網路的完整工具鏈。

---

## v1.1 重點：DNS 查詢工具移植

### 工具鏈

```
dns tool (userspace) → user::socket/send/receive
  → xv8 kernel UDP stack → E1000 → QEMU user-mode NAT → internet
```

### 異動摘要

| 檔案 | 變更 |
|------|------|
| `xv8/user/bin/dns.rs` | 新增 DNS A record 查詢工具（`no_std`，固定陣列） |
| `xv8/user/testbin/netdns.rs` | 新增 DNS 自動化整合測試 |
| `xv8/user/Cargo.toml` | 註冊 `dns` + `_netdns` binary |
| `xv8/user/testbin/testrunner.rs` | 加入 `_netdns` 測試 |
| `xv8/mkfs.sh` | `dns` binary 納入 fs.img |
| `xv8/.cargo/config.toml` | 加入 `hostfwd=udp::19999-:19999` |

### 驗證

- QEMU 10 個整合測試全部 PASS
- `dns 8.8.8.8 example.com` 成功回傳 A records

### QEMU hostfwd

Host 可透過 UDP 19999 送封包到 guest，方便未來開發 listen/monitoring 工具。

## 結論

v1.1 雖然變動不大，但意義在於驗證了 xv8 的使用者空間網路工具鏈已完整可運作：
1. **Userspace DNS client** 透過 kernel syscall → UDP stack → E1000 → QEMU NAT，成功解析網域名稱
2. **QEMU hostfwd** 為 host↔guest 雙向 UDP 通訊鋪路
3. **netdns 自動化測試** 確保 DNS 路徑在 CI 中持續通過
