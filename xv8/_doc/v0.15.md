# v0.15 - Environment & Parameter

Date: 2026-05-31

## New Syscalls (5 added, total 107)

| Num | Name | Description |
|-----|------|-------------|
| 103 | getenv | Get environment variable value |
| 104 | setenv | Set environment variable |
| 105 | unsetenv | Remove environment variable |
| 106 | clearenv | Clear all environment variables |
| 107 | getpagesize | Get memory page size |

## Changes

### kernel/src/proc.rs
- Added `env: Vec<String>` field to `ProcData`
- Each entry stored as "KEY=VALUE" string
- Initialized empty in `ProcData::new()`
- Cloned from parent in `fork()`
- Added `use alloc::vec::Vec` import

### kernel/src/syscall.rs
- Added syscall numbers 103-107 to `Syscall` enum
- Added `TryFrom` cases and dispatch arms

### kernel/src/sysproc.rs
- `sys_getenv`: search env by name, copy value to user buffer
- `sys_setenv`: add new or update existing entry (respects overwrite flag)
- `sys_unsetenv`: remove entry by name
- `sys_clearenv`: clear entire env vector
- `sys_getpagesize`: returns `PGSIZE` (4096)

### user/src/syscall.rs
- Added raw and safe wrapper functions for all 5 syscalls

## Implementation Details
- Environment stored as `Vec<String>` with "KEY=VALUE" entries
- `getenv` returns up to `buf_len` bytes of the value
- `setenv` validates name (non-empty, no '=' in name)
- `getpagesize` returns 4096 (RISC-V page size)

## Testing
- All 8 tests pass: fs, pipe, proc, fd, sbrk, cow, net, syscall
