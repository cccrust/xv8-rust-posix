# v0.7 - Time and Timer Syscalls

Date: 2026-05-31

## New Syscalls (5 added, total 70)

| Num | Name | Description |
|-----|------|-------------|
| 66 | time | Get current time (seconds since epoch) |
| 67 | nanosleep | High-precision sleep |
| 68 | clock_gettime | Get clock time (sec + nsec) |
| 69 | clock_getres | Get clock resolution |
| 70 | clock_settime | Set clock time (stub) |

## Changes

### kernel/src/syscall.rs
- Added syscall numbers 66-70 to `Syscall` enum
- Added TryFrom cases and match arms for new syscalls

### kernel/src/sysproc.rs
- Implemented `sys_time`: returns TICKS / 100 (converts 10ms ticks to seconds)
- Implemented `sys_nanosleep`: blocks for specified seconds using TICKS-based sleep
- Implemented `sys_clock_gettime`: returns (seconds, nanoseconds) tuple
- Implemented `sys_clock_getres`: returns (0, 100) for 100ns resolution
- Implemented `sys_clock_settime`: stub returning success

### user/src/syscall.rs
- Added raw syscall wrappers: time, nanosleep, clock_gettime, clock_getres, clock_settime
- Added public wrapper functions with proper error handling

### user/testbin/syscall.rs
- Added tests for time(), nanosleep(), clock_gettime(), clock_getres()

## Implementation Notes

- TICKS increments every 10ms (100 ticks per second)
- time() returns seconds since boot (TICKS / 100)
- nanosleep() accepts seconds and nanoseconds, blocks using sleep() on TICKS channel
- clock_gettime returns real time based on TICKS (not wall clock time)
- clock_getres returns 100 nanoseconds as the resolution

- All 8 tests pass: fs, pipe, proc, fd, sbrk, cow, net, syscall
