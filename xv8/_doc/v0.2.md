# xv8 v0.2 - POSIX System Call 標準相容性更新

## 更新日期
2026-05-30

## 主要變更

### 1. OpenFlag 修正為 POSIX 標準

修正 `kernel/src/file.rs` 中的 OpenFlag 定義，使其符合 POSIX 標準：

```rust
// 修正前 (錯誤):
pub const READ_ONLY: usize = 0x000;
pub const WRITE_ONLY: usize = 0x001;
pub const READ_WRITE: usize = 0x002;
pub const CREATE: usize = 0x200;
pub const TRUNCATE: usize = 0x400;

// 修正後 (POSIX 標準):
pub const READ_ONLY: usize = 0x000;
pub const WRITE_ONLY: usize = 0x001;
pub const READ_WRITE: usize = 0x002;
pub const CREATE: usize = 0x040;
pub const EXCLUSIVE: usize = 0x080;
pub const TRUNCATE: usize = 0x200;
pub const APPEND: usize = 0x400;
pub const NON_BLOCK: usize = 0x800;
```

### 2. Stat 結構擴展

新增 uid, gid, mode, atime, mtime 欄位以支援 POSIX 標準的檔案屬性：

```rust
pub struct Stat {
    pub dev: u32,
    pub ino: u32,
    pub r#type: InodeType,
    pub mode: u16,      // 新增
    pub nlink: u16,
    pub uid: u16,       // 新增
    pub gid: u16,       // 新增
    pub size: u64,
    pub atime: u32,     // 新增
    pub mtime: u32,     // 新增
}
```

### 3. InodeInner 結構擴展

同步更新 InodeInner 以支援新的 Stat 欄位：

```rust
pub struct InodeInner {
    pub valid: bool,
    pub r#type: InodeType,
    pub major: u16,
    pub minor: u16,
    pub mode: u16,      // 新增
    pub nlink: u16,
    pub uid: u16,       // 新增
    pub gid: u16,       // 新增
    pub size: u32,
    pub addrs: [u32; NDIRECT + 1],
}
```
