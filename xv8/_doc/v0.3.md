# xv8 v0.3 - 剩餘 POSIX System Calls 實作

## 更新日期
2026-05-30

## 主要變更

### 1. InodeType 擴展 - 新增 SymLink 類型

```rust
pub enum InodeType {
    Free = 0,
    Directory = 1,
    File = 2,
    Device = 3,
    SymLink = 4,  // 新增
}
```

### 2. 新增 System Calls (10 個)

| syscall | 編號 | 說明 |
|---------|------|------|
| symlink | 44 | 建立符號連結 |
| readlink | 45 | 讀取符號連結目標 |
| utimensat | 46 | 改變檔案時間戳 |
| alarm | 47 | 設定鬧鐘 |
| times | 48 | 取得行程時間 (Tms 結構) |
| sync | 49 | 同步檔案系統 |
| getpgrp | 50 | 取得程序群組 ID |
| setpgid | 51 | 設定程序群組 ID |
| setsid | 52 | 建立新 session |
| nice | 53 | 改變程序優先權 |

## 修改的檔案

- `kernel/src/fs.rs` - InodeType 新增 SymLink = 4
- `kernel/src/syscall.rs` - 新增 10 個 syscall 號碼與分派
- `kernel/src/sysfile.rs` - 新增 symlink/readlink/utimensat 處理函數
- `kernel/src/sysproc.rs` - 新增 alarm/times/sync/getpgrp/setpgid/setsid/nice 處理函數
- `user/bin/ls.rs` - 更新以處理 SymLink 類型

## Syscall 總數

從 44 個增加到 54 個 system calls。

## 用戶空間影響

- `ls` 命令現在可以正確顯示符號連結 (顯示為 `l`)
- 符號連結可以使用 `ln -s` 建立
- 可以使用 `readlink` 讀取符號連結目標

## 已知限制

- `utimensat` - 目前只是 stub，未實際更新 inode 時間戳
- `alarm` - 目前只是 stub，未實作信號機制
- `times` - 目前回傳全 0 的時間值
- `setpgid` - 跨程序設定尚未支援
- `nice` - 目前只是 stub，未實作優先權機制
