# v0.11 - TTY Extension

Date: 2026-05-31

## New Syscalls (5 added, total 89)

| Num | Name | Description |
|-----|------|-------------|
| 85 | ttyname | Get terminal device name |
| 86 | ttyioctl | TTY-specific ioctl operations |
| 87 | tcgetsid | Get session ID associated with terminal |
| 88 | tcflow | Terminal flow control |
| 89 | tcflush | Flush terminal buffers |

## Changes

### kernel/src/syscall.rs
- Added syscall numbers 85-89 to `Syscall` enum
- Added TryFrom cases and match arms for new syscalls
- Added `SysError::NotATty` (error code 25)

### kernel/src/console.rs
- Added `Console::foreground_pid()` public getter for foreground PID
- Field `foreground_pid` remains private, accessed via the getter

### kernel/src/sysproc.rs
- `sys_ttyname`: returns "/dev/console" to user buffer for console fd
- `sys_ttyioctl`: delegates to `Console::ioctl` for TTY-specific operations
- `sys_tcgetsid`: returns foreground process PID from console
- `sys_tcflow`: no-op (console doesn't support flow control)
- `sys_tcflush`: no-op (console output is not buffered)

## Implementation Notes
- ttyname writes `/dev/console\0` to user-provided buffer (ttyname_r style: fd, buf, len)
- ttyioctl supports CONSOLE_SET_RAW and CONSOLE_SET_FG_PID commands
- tcgetsid returns foreground PID (no session infrastructure yet)
- tcflow and tcflush are simplified no-ops returning success

- All 8 tests pass: fs, pipe, proc, fd, sbrk, cow, net, syscall
