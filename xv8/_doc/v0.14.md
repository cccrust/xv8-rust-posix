## Changes

### kernel/src/signal.rs
- Added `SIG_BLOCK(0)`, `SIG_UNBLOCK(1)`, `SIG_SETMASK(2)` constants
- Added `SigFrame` struct for saving/restoring context on user stack
- Added `is_fatal_signal()` helper

### kernel/src/proc.rs
- Added `sigactions: [SigAction; 32]` field to `ProcData`
- Inherited by child in `fork()`

### kernel/src/syscall.rs
- Added syscall numbers 97-102 to `Syscall` enum
- Added `TryFrom` cases and dispatch arms

### kernel/src/sysproc.rs
- `sys_sigaction`: retrieve/update per-signal actions
- `sys_sigprocmask`: atomic mask modification (SIG_BLOCK/UNBLOCK/SETMASK)
- `sys_sigpending`: copy pending signal set to user space
- `sys_sigsuspend`: set mask, poll until signal pending, return -EINTR
- `sys_sigreturn`: read SigFrame from user stack, restore trapframe + mask
- `sys_killpg`: find all procs matching pgrp, send signal to each

### kernel/src/trap.rs
- Added `deliver_pending_signals()` called at top of `usertrapret()`
- Handles SIG_DFL (default action: fatal signals kill process)
- Handles SIG_IGN (clear pending)
- Handles user handlers: push SigFrame on user stack, set epc to handler

### user/src/syscall.rs
- Added raw and safe wrapper functions for all 6 syscalls

### kernel/src/abi.rs
- Exported signal constants and `SigAction` struct for user space

## Signal Delivery Flow

1. Before returning to user space, `usertrapret()` calls `deliver_pending_signals()`
2. Checks `pending & !blocked` bitmask for unblocked signals
3. For each unblocked signal (lowest first):
   - **SIG_DFL**: if fatal → `exit(-sig)`, else ignore
   - **SIG_IGN**: clear and continue
   - **User handler**: save trapframe to user stack SigFrame, set mask, enter handler
4. Handler must call `sigreturn()` to restore context

## Implementation Notes
- Handler trampoline: without a fixed vDSO page, handlers must call `sigreturn()` explicitly
- `sigsuspend` uses polling (proc::r#yield()) rather than sleep/wakeup
- `killpg` handles all signals including SIGKILL (via the pending bit)
- `SysError::Interrupted` is returned when a signal interrupts a syscall
