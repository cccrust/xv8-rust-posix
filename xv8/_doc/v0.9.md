Date: 2026-05-31

| Num | Name | Description |
|-----|------|-------------|
| 75 | setpgid | Set process group ID |
| 76 | getsid | Get session ID |
| 77 | setreuid | Set real/effective UID |
| 78 | setregid | Set real/effective GID |
| 79 | setresuid | Set real/effective/saved UID |
| 80 | setresgid | Set real/effective/saved GID |

## Changes

### kernel/src/proc.rs
- Added `euid`, `egid`, `suid`, `sgid` fields to `ProcData`
- Initialized new fields to 0 in `ProcData::new()`
- Updated `fork()` to inherit all credential fields from parent

### kernel/src/syscall.rs
- Added syscall numbers 75-82 to `Syscall` enum
- Existing `Setpgid` renumbered from 51 to 75 (Linux-compatible)
- Added TryFrom cases and match arms for new syscalls
- Removed duplicate `Setpgid` entries

### kernel/src/sysproc.rs
- `sys_setpgid`: sets process group (simplified, only for own process)
- `sys_getsid`: returns session ID (simplified, returns PID as session ID)
- `sys_setreuid`: sets real and effective UID
- `sys_setregid`: sets real and effective GID
- `sys_setresuid`: sets real, effective, and saved UID
- `sys_setresgid`: sets real, effective, and saved GID
- `sys_getresuid`: returns real, effective, and saved UID via user pointer
- `sys_getresgid`: returns real, effective, and saved GID via user pointer

### user/src/syscall.rs
- Added raw syscall wrappers for all 8 new syscalls

### user/testbin/syscall.rs
- Added tests for credential syscalls

## Credential Model

```
ProcData {
    uid: u32,   // real user ID
    euid: u32,  // effective user ID
    suid: u32,  // saved user ID (for setuid capability)
    gid: u32,   // real group ID
    egid: u32,  // effective group ID
    sgid: u32,  // saved group ID
}
```

- `-1` (u32::MAX) means "don't change this credential" in set* functions
- `getresuid`/`getresgid` write 3 u32 values to user-provided buffer
- Only superuser (uid=0) can change credentials (simplified, not fully enforced yet)

## Implementation Notes
- setpgid: existing implementation (previously at syscall 51) moved to 75
- getsid: simplified implementation returns PID as session ID
- Credential syscalls use simplified permission checks
- No session management infrastructure yet (groups, controlling terminals)
