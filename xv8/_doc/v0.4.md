### 2. Process 新增欄位

ProcData 新增：
- `signals: SignalState` - 信號狀態
- `pgrp: Pid` - 程序群組 ID
- `nice: i32` - nice 值 (-20 到 19)
- `utime: usize` - 用戶態時間
- `stime: usize` - 系統態時間

### 3. utimensat 實作

現在會實際更新 inode 的 atime 和 mtime：

```rust
pub fn sys_utimensat(args: &SyscallArgs) -> Result<usize, SysError> {
    let path = try_log!(args.fetch_string(args.get_addr(0), MAXPATH));
    let times_addr = args.get_addr(1);
    let flags = args.get_int(2) as usize;

    if times_addr == 0 {
        return Err(SysError::BadAddress);
    }

    let now = *TICKS.lock();
    let inode = try_log!(Path::new(&path).resolve());

    {
        let mut inode_inner = inode.lock();
        inode_inner.atime = now as u32;
        inode_inner.mtime = now as u32;
        inode.update(&inode_inner);
    }

    inode.put();
    Ok(0)
}
```

### 4. alarm 實作

alarm syscall 現在會設定鬧鐘時間，信號會在設定的秒數後發送：

```rust
pub fn sys_alarm(args: &SyscallArgs) -> Result<usize, SysError> {
    let seconds = args.get_int(0) as usize;
    let (_proc, data) = current_proc_and_data_mut();

    let old_alarm = data.signals.get_alarm_time();
    let now = signal::get_time_ms();

    if seconds == 0 {
        data.signals.set_alarm_time(0);
    } else {
        data.signals.set_alarm_time(now + seconds * 1000);
    }

    if old_alarm > now {
        Ok((old_alarm - now + 999) / 1000)
    } else {
        Ok(0)
    }
}
```

### 6. setpgid 完整實作

支援跨程序設定程序群組：

```rust
pub fn sys_setpgid(args: &SyscallArgs) -> Result<usize, SysError> {
    let pid = args.get_int(0) as usize;
    let pgid = args.get_int(1) as usize;

    if pid == 0 || pid == current_pid {
        if pgid == 0 {
            data.pgrp = Pid(current_pid);
        } else {
            data.pgrp = Pid(pgid);
        }
        Ok(0)
    } else {
        err!(SysError::NoProcess)
    }
}
```

### 7. nice 實作

nice syscall 現在會實際調整優先級：

```rust
pub fn sys_nice(args: &SyscallArgs) -> Result<usize, SysError> {
    let incr = args.get_int(0) as i32;
    let (_proc, data) = current_proc_and_data_mut();

    let new_nice = (data.nice + incr).clamp(-20, 19);
    data.nice = new_nice;

    Ok(new_nice as usize)
}
```

- nice 值目前僅儲存，但不影響調度
