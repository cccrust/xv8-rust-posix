## FIFO (Named Pipe) Implementation

Named pipes use a shared pipe buffer across multiple opens:
- `mkfifo` creates a special FIFO inode in the filesystem
- When a process opens the FIFO, `sys_open` checks `FIFO_TABLE`:
  - If a pipe already exists for this inode, reuse it
  - If not, allocate a new pipe and store it in the table
- The file type is set to `FileType::Pipe`, so read/write operations work via `Pipe`

## pipe2 Implementation
- Accepts a `flags` argument (supports `O_NONBLOCK` etc.)
- Currently wraps `sys_pipe` and ignores flags

## Known Issues
- pipe2 ignores flags (O_NONBLOCK, O_CLOEXEC not yet supported in pipe implementation)
- FIFO opens don't block waiting for reader/writer (simplified implementation)
- FIFO table entries are never cleaned up
