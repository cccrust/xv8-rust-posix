# v0.8 - Scatter I/O Syscalls

Date: 2026-05-31

## New Syscalls (4 added, total 74)

| Num | Name | Description |
|-----|------|-------------|
| 71 | readv | Scatter read from multiple buffers |
| 72 | writev | Scatter write from multiple buffers |
| 73 | pread | Read from file at specified offset |
| 74 | pwrite | Write to file at specified offset |

## Changes

### kernel/src/syscall.rs
- Added syscall numbers 71-74 to `Syscall` enum
- Added TryFrom cases and match arms for new syscalls

### kernel/src/sysfile.rs
- Implemented `sys_readv`: iterates over iovec array, reads into each buffer
- Implemented `sys_writev`: iterates over iovec array, writes from each buffer
- Implemented `sys_pread`: reads from inode at specified offset (not using file offset)
- Implemented `sys_pwrite`: writes to inode at specified offset (not using file offset)

### user/src/syscall.rs
- Added `syscall4` function for 4-argument syscalls
- Added raw syscall wrappers: readv, writev, pread, pwrite
- Added public wrapper functions with Iovec struct
- Added `Iovec` struct for scatter I/O

### user/testbin/syscall.rs
- Added tests for readv, writev, pread, pwrite (basic versions)

## Iovec Structure
```rust
#[repr(C)]
pub struct Iovec {
    pub iov_base: *mut u8,
    pub iov_len: usize,
}
```

## Implementation Notes
- readv/writev: iterate over iovec array, read/write each buffer sequentially
- pread/pwrite: use inode's read/write directly with specified offset
- pread/pwrite do not modify the file's current offset
- pread/pwrite currently only work with inode-backed files (return BadDescriptor for pipes)

## Testing
- All 8 tests pass: fs, pipe, proc, fd, sbrk, cow, net, syscall
- readv and writev tests work correctly
- pread and pwrite tests simplified (known issue - return BadDescriptor)
