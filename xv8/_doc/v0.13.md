# v0.13 - Group Management

Date: 2026-05-31

## New Syscalls (3 added, total 96)

| Num | Name | Description |
|-----|------|-------------|
| 94 | setgroups | Set supplementary group IDs |
| 95 | getgroups | Get supplementary group IDs |
| 96 | initgroups | Initialize supplementary group access list |

## Changes

### kernel/src/proc.rs
- Added `groups: [u32; 16]` and `ngroups: usize` fields to `ProcData`
- Initialized to zero in `ProcData::new()`
- Inherited by child in `fork()`

### kernel/src/syscall.rs
- Added syscall numbers 94-96 to `Syscall` enum
- Added `TryFrom` cases and dispatch arms

### kernel/src/sysproc.rs
- `sys_setgroups`: copies up to 16 gid values from user-space list, stores in proc
- `sys_getgroups`: copies gid list back to user-space, returns count
- `sys_initgroups`: reads username string, sets supplementary groups to [group]

### user/src/syscall.rs
- Added raw and safe wrapper functions for all three syscalls

## Implementation Details

- Maximum NGROUPS = 16 (stored as fixed-size array)
- `setgroups` validates size ≤ 16, copies from user memory via `copy_from`
- `getgroups` handles NULL list pointer (returns count only)
- `initgroups` is a stub that only adds the given group (no `/etc/group` parsing yet)

## Testing
- All 8 tests pass: fs, pipe, proc, fd, sbrk, cow, net, syscall
