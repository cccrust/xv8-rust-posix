# v0.12 - Path & System Configuration

Date: 2026-05-31

## New Syscalls (4 added, total 93)

| Num | Name | Description |
|-----|------|-------------|
| 90 | pathconf | Get file path configuration value |
| 91 | fpathconf | Get file descriptor configuration value |
| 92 | sysconf | Get system configuration value |
| 93 | confstr | Get configuration-defined string value |

## Changes

### kernel/src/syscall.rs
- Added syscall numbers 90-93 to `Syscall` enum
- Added TryFrom cases and match arms

### kernel/src/sysproc.rs
- `sys_pathconf`: returns predefined values for path configuration names
- `sys_fpathconf`: returns predefined values for fd configuration names
- `sys_sysconf`: returns system configuration values (pagesize, open_max, etc.)
- `sys_confstr`: returns configuration strings (e.g. `_CS_PATH` = "/bin:/usr/bin")
