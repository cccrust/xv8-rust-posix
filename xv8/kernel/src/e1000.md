# E1000 網卡驅動 — e1000.rs

Intel E1000 是 QEMU 提供的乙太網路卡，xv8 用它實現網路功能。

## QEMU 配置

```
QEMU virt machine
         │
         │ PCIe (無獨立 PCIe 主控器，使用 MMIO)
         │
         ▼
    E1000 NIC
    - Vendor: 0x8086
    - Device: 0x100E (82540EM)
    - MMIO: 0x40000000
    - IRQ: 33
```

## 傳送流程

```rust
impl NetDevice for E1000Interface {
    fn transmit(&self, data: &[u8]) -> Result<(), NetError> {
        let mut e1000 = E1000.lock();

        let i = e1000.tx_index;

        // 複製資料到傳送緩衝區
        let tx_buf = TX_BUF.as_ptr().add(i * TX_BUF_SIZE);
        unsafe {
            ptr::copy_nonoverlapping(data.as_ptr(), tx_buf, data.len());
        }

        // 設定描述符
        e1000.tx_rings[i].address = tx_buf as u64;
        e1000.tx_rings[i].length = data.len() as u16;
        e1000.tx_rings[i].cmd = CMD_EOP | CMD_RS | CMD_IFCS;
        e1000.tx_rings[i].status = 0;

        // 通知硬體
        e1000.write_reg(E1000_MMIO_TDT, i as u32);

        e1000.tx_index = (i + 1) % TX_RING_SIZE;
        Ok(())
    }
}
```

## 接收流程

```rust
impl NetDevice for E1000Interface {
    fn poll_receive(&self) -> Option<Box<[u8]>> {
        let mut e1000 = E1000.lock();

        let i = e1000.rx_index;

        if e1000.rx_rings[i].status & RX_STATUS_DD == 0 {
            return None;  // 沒有收到資料
        }

        let len = e1000.rx_rings[i].length as usize;
        let rx_buf = RX_BUF.as_ptr().add(i * RX_BUF_SIZE);

        let mut data = vec![0u8; len];
        unsafe {
            ptr::copy_nonoverlapping(rx_buf, data.as_mut_ptr(), len);
        }

        // 重新設定描述符
        e1000.rx_rings[i].status = 0;

        e1000.write_reg(E1000_MMIO_RDT, i as u32);

        e1000.rx_index = (i + 1) % RX_RING_SIZE;
        Some(data.into_boxed_slice())
    }
}
```

## 初始化

```rust
pub unsafe fn init() {
    let base = E1000_BASE.load(Ordering::SeqCst);

    let mut e1000 = E1000.lock();
    e1000.base = base;

    // 停用傳送和接收
    e1000.write_reg(E1000_MMIO_TCTL, 0);
    e1000.write_reg(E1000_MMIO_RCTL, 0);

    // 設定描述符環
    e1000.write_reg(E1000_MMIO_TDBAL, (&e1000.tx_rings as *const _ as u32));
    e1000.write_reg(E1000_MMIO_RDBAL, (&e1000.rx_rings as *const _ as u32));

    // 啟用傳送和接收
    e1000.write_reg(E1000_MMIO_TCTL, TCTL_EN | TCTL_PSP);
    e1000.write_reg(E1000_MMIO_RCTL, RCTL_EN | RCTL_BAM);

    // 設定中斷
    e1000.write_reg(E1000_MMIO_IMS, TXDW | RXDMT0 | RXO | RXT0);
}
```

## 中斷處理

```rust
pub fn handle_interrupt() {
    let mut e1000 = E1000.lock();

    // 讀取並清除中斷
    let icr = e1000.read_reg(E1000_MMIO_ICR);
    e1000.write_reg(E1000_MMIO_ICR, 0xFFFFFFFF);

    if icr & TXDW != 0 {
        // 傳送完成
    }

    if icr & RXDMT0 != 0 || icr & RXT0 != 0 {
        // 接收完成，通知網路堆疊
        proc::wakeup(Channel::Network);
    }
}
```
