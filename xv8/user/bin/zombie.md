# Zombie — 殭屍行程展示

`zombie` 是一個展示行程狀態的教學程式，用於說明 Unix 行程模型中殭屍行程的產生與危害。

## 殭屍行程是什麼

當子行程使用 `exit()` 終止後，核心保留了其 PCB（行程控制區塊），包含退出碼與資源使用統計。若父行程未呼叫 `wait()` 或 `waitpid()` 取得此資訊，該行程記錄永久殘留——此即為殭屍行程（defunct process）。

## 殭屍的資源足跡

殭屍行程已釋放所有記憶體與檔案描述符，僅保留：
- PID（行程 ID，無法被其他行程重用）
- PCB 中的終止狀態資訊
- /proc 中的條目

大量殭屍行程會耗盡 PID 上限，導致系統無法建立新行程。

## 清理方法

- **正常情況**：父行程呼叫 `wait()` 收集子行程退出狀態
- **孤兒殭屍**：若父行程先終止，init（PID 1）收養孤兒並自動 `wait()`
