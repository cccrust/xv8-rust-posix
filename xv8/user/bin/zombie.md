# zombie — 測試殭屍程序

zombie 建立一個立即退出的子程序，父程序 sleep 5 秒後才退出，示範殭屍程序的產生。

## 使用方式

```bash
zombie
```

## 實作

```rust
fn main(_args: Args) {
    if fork().unwrap() > 0 {
        // 父程序：睡眠 5 秒後退出
        let _ = sleep(5);
    }
    // 子程序：立即退出
    exit(0);
}
```

## 殭屍程序產生

```
時間線：
    │
fork() ──────────────────────────────────────
    │                                          │
    ├─ 子程序: exit(0)  ←── 立即退出           │
    │                                          │
    ├─ 父程序: sleep(5)                       │
    │        (此時子程序是殭屍)                  │
    │                                          │
    └─ 5秒後，父程序退出或呼叫 wait()           │
       (子程序資源被釋放)                        │
```

## 殭屍程序的意義

子程序退出後：
- 核心保留程序資訊（PID、退出碼、資源使用）
- 等待父程序呼叫 `wait()` 讀取退出狀態
- 父程序未呼叫 `wait()` 前，子程序處於殭屍狀態

## 為何需要殭屍？

- 父程序需要知道子程序的退出狀態
- 保留資源使用統計供父程序查詢

## 測試方式

```bash
zombie &
ps
# 可以看到 zombie 程序狀態為 Z (殭屍)
sleep 6
ps
# 殭屍已被回收（父程序退出或 wait 了）
```

## 與 xv8 的整合

- `fork()` 建立子程序
- `exit(0)` 子程序退出
- `sleep()` 父程序延遲
- `wait()` 回收子程序（由 init 執行）
