# Demo — 能力展示程式

`demo` 是 xv8 的展示程式，運行於使用者空間，展示作業系統的核心能力。它序列執行多項操作來驗證系統功能完整性：

- **行程管理**：fork、exec、wait 等系統呼叫的正確性
- **檔案系統**：檔案建立、讀寫、目錄瀏覽
- **記憶體管理**：sbrk、mmap 記憶體擴展
- **網路通訊**：socket 操作、TCP/UDP 資料傳送

展示程式的目的在於證明使用者空間與核心的互動正常，所有 ABI 介面符合預期。這是在開發階段驗證核心變更未破壞基本功能的快速檢查工具。
