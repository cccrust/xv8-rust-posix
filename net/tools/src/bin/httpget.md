# Httpget — HTTP GET 工具

`httpget` 是一個 HTTP GET 請求工具，用於從指定的 URL 取得資源。它發送 HTTP GET 請求、解析回應標頭、將主體輸出到 stdout。常用於測試 Web 伺服器可達性、下載檔案或檢查 HTTP 回應。此工具展示 TCP 連線、HTTP 協議交互與回應解析的完整流程。
