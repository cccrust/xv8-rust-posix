# HTTP Server — HTTP 伺服器

`http_server` 是一個簡單的 HTTP 伺服器，監聽指定埠號，為請求提供靜態檔案或動態回應。它展示基本的 socket API、HTTP 請求解析與回應產生。HTTP 伺服器遵循 RFC 9112 規範處理請求和回應。可用於測試網路工具鏈或提供簡易的 Web 服務。
