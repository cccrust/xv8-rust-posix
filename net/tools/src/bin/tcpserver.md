# TCP Server — TCP 伺服器

`tcpserver` 是一個精簡的 TCP 伺服器工具，監聽指定埠號，接受連線並處理資料。它展示 TCP socket 的監聽（listen）、接受（accept）、讀寫（recv/send）的標準伺服器流程。支援基本的資料回顯或簡單協定的處理。
