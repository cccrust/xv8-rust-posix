# TCP Client — TCP 客戶端

`tcpclient` 是一個精簡的 TCP 客戶端工具，用於連接指定的 TCP 伺服器埠號，傳送資料並接收回應。它展示 TCP socket 的連線建立（connect）、資料傳送（send）與接收（recv）的標準流程。此工具可用於測試 TCP 服務的可達性與基本的伺服器回應。
