# net v0.1 — 基礎架構 + DNS / ICMP 工具

## 目標

建立 `net/` workspace 基礎架構，實作三支可在 macOS 主機上執行的網路工具：
`ping`、`host`、`dns`。

## 結構

```
net/
├── _doc/
│   ├── plan.md              # 總體規劃
│   └── v0.1.md              # 本文件
├── Cargo.toml               # workspace root
├── test.sh                  # 測試腳本
├── libnet/                  # 共用網路函式庫
│   ├── Cargo.toml

│       ├── lib.rs
│       ├── dns.rs           # DNS 查詢/回應封包構造與解析
│       ├── icmp.rs          # ICMP echo (ping)
```

## libnet 模組

### util.rs

| 函式 | 說明 |
|------|------|
| `ip_to_string` | `[u8;4]` → `"1.2.3.4"` |
| `string_to_ip` | `"1.2.3.4"` → `Option<[u8;4]>` |
| `internet_checksum` | RFC 1071 網際網路 checksum |
| `encode_dns_name` | `"www.example.com"` → DNS wire format (含 length prefix + null terminator) |
| `build_ipv4_header` | 構造 IPv4 header + payload |
| `fmt_duration_us` | 格式化時間（ms 或 s） |

### dns.rs

完整 DNS 查詢/回應解析，支援：

- A record (type 1) 與 AAAA record (type 28) 查詢
- DNS name compression pointer (0xc0) 解壓
- 自動 random transaction ID
- 5 秒 timeout

**資料結構：** `DnsHeader`、`DnsQuestion`、`DnsRecord`

**公開函式：**
- `build_query(domain, qtype, id)` → `Vec<u8>`
- `parse_response(data)` → `Option<(DnsHeader, Vec<DnsRecord>)>`
- `query(server, domain, qtype)` → `Result<(DnsHeader, Vec<DnsRecord>), String>`

**測試 (3)：**
- `test_build_and_parse_query` — 構造 query 後解析 header
- `test_dns_name_roundtrip` — 編碼後解碼 DNS name
- `test_dns_name_with_pointer` — 含 compression pointer 的 name 解碼

### icmp.rs

ICMPv4 echo request/reply，使用 macOS `SOCK_DGRAM` + `IPPROTO_ICMP`（需 `sudo`）。

**資料結構：** `IcmpEcho`

**公開函式：**
- `ping(target, id, seq, timeout)` → `Result<(Duration, usize), String>`

## 工具

### ping

```
Usage: ping <ip>

PING 127.0.0.1: 56 data bytes
64 bytes from 127.0.0.1: icmp_seq=0 time=0.5 ms

--- 127.0.0.1 ping statistics ---
4 packets transmitted, 4 received, 0% packet loss
rtt avg = 0.500 ms
```

- 發送 4 個 ICMP echo request，間隔 1 秒
- 顯示每個 reply 的 RTT
- 最後顯示統計（送收數量、遺失率、平均 RTT）
- **macOS 上需要 `sudo`**（ICMP raw socket 權限）

### host

```
Usage: host <domain> [dns-server]

$ host google.com 8.8.8.8
google.com has address
  142.251.170.100
  ...
  google.com has IPv6 address 2404:6800:4008:...
```

- 查詢 A + AAAA record
- 預設 DNS server 為 `8.8.8.8`

### dns

```
Usage: dns <domain> [dns-server]

$ dns google.com 8.8.8.8
Query: google.com -> 8.8.8.8
  A  142.251.170.100 (TTL=175)
  ...
```

- 查詢 A record，顯示 TTL

## 已知限制

- `ping` 僅支援 macOS（`#[cfg(target_os = "macos")]`）；Linux 需 Linux-specific ICMP socket 實作
- `ping` 需要 `sudo`，無權限時無法使用
- `host` 的 IPv6 位址輸出格式較簡陋（無 `:` 壓縮）
- 無 unit test 覆蓋 `icmp.rs`（需 root）
- `tcpclient`/`tcpserver` 僅為 stub
