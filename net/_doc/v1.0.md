# net v1.0 — xv8 QEMU 網路整合完成

## 狀態 ✅

xv8 在 QEMU RISC-V virt 機器上透過 E1000 PCIe 網卡 + QEMU user-mode NAT 成功收送 UDP 封包。

## 實作摘要

### 1.0.1：QEMU 網路後端

**xv8/.cargo/config.toml** 使用：
```
-netdev user,id=net0 -device e1000,netdev=net0
```

`-netdev user` 是 QEMU 內建用戶模式 NAT，不需 tap/tun、跨平台（macOS/Linux/Windows）。

**xv8/kernel/src/e1000.rs** 變更：
- 靜態 IP 從 `192.168.10.2/24` 改為 `10.0.2.15/24`（QEMU user-mode 預設 guest IP）
- 加入預設路由到 gateway `10.0.2.2`（DHCP 完成前即可通訊）

### 1.0.2：自動測試

**xv8/user/testbin/neteth.rs**：兩個測試案例
1. `test_udp_send_to_host` — 輪詢傳送 UDP 到 `10.0.2.2:9999`，驗證 DHCP + 路由 + ARP + E1000 TX 路徑
2. `test_udp_listen_and_loopback_send` — 確認 loopback 在 E1000 註冊後仍正常運作

透過 `./test.sh` 或 `./run.sh` 執行，`_testrunner` 自動跑包含 `_neteth` 在內的所有 9 個測試。

## QEMU User-Mode 網路位址

| 角色 | IP |
|------|-----|
| Guest (xv8) | 10.0.2.15/24 |
| Host/gateway | 10.0.2.2 |
| DNS server | 10.0.2.3 |
| Subnet | 10.0.2.0/24 |

## 驗證方法

1. **手動測試**：host 開 `nc -lu 9999`，xv8 shell 執行 `udp send 10.0.2.2 9999 "hello"`
2. **自動測試**：`cd xv8 && ./test.sh`

## 待完成

### 1.0.3：xv8-libc 網路 syscall wrapper
在 `xv8rust/xv8-libc/src/` 新增：

| 函式 | 對應 kernel syscall |
|------|-------------------|
| `sys_socket(port) -> isize` | `SYS_SOCKET` |
| `sys_send(fd, buf, len, dest_ip, dest_port) -> isize` | `SYS_SEND` |
| `sys_receive(fd, buf, len, src_ip, src_port) -> isize` | `SYS_RECEIVE` |

### 1.0.4：xv8-user-std 網路抽象層
在 `xv8rust/xv8-user-std/` 新增 `net.rs`，提供類似 `std::net` 的介面：
- `UdpSocket`（bind, send_to, recv_from）
- `Ipv4Addr`（封裝）

### 1.0.5：net/ 工具移植
將 `libnet/` 和 `tools/` 改為支援雙後端（std / xv8）：
- trait 化：`DnsResolver`、`NtpClient`、`IcmpPing`、`TftpClient`、`TcpConnector`
- macOS 上用 `std::net`，xv8 上用 xv8-user-std

## 非目標
- TCP 移植（xv8 kernel 無 TCP 棧）
- 完整 `std::net` 相容層（僅最小可用 UDP）
