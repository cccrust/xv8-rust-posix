# net v0.3 — 進階 UDP/TCP 工具

## 目標

實作 NTP 客戶端、WHOIS 查詢、TFTP 客戶端，可在 macOS 主機上運作。

## 工具

### ntp

NTP (RFC 5905) 客戶端，查詢 NTP 伺服器取得精確時間。

```
Usage: ntp <server>

$ ntp pool.ntp.org
NTP query to pool.ntp.org
  Stratum:      2
  Poll:         0s
  Precision:    -24s
  Root delay:   0.000153s
  Root disp:    0.000336s
  Reference ID: 0x11fd747d
  Timestamp:    2026-06-01 02:23:32.248 UTC
```

### whois

WHOIS (RFC 3912) 查詢，透過 TCP port 43。

```
Usage: whois <query> [server]

$ whois google.com
Domain Name: GOOGLE.COM
   Registry Domain ID: 2138514_DOMAIN_COM-VRSN
   ...
```

- 預設 server：`whois.verisign-grs.com`（.com TLD）
- 可自訂 server

### tftp

TFTP (RFC 1350) 客戶端，支援下載（octet mode）。

```
Usage: tftp <host> get <remote-file> [local-file]
       tftp <host> put <local-file> [remote-file]

$ tftp 192.168.1.1 get firmware.bin
Downloading firmware.bin from 192.168.1.1...
Saved 65536 bytes to firmware.bin
```

- 支援 RRQ/DATA/ACK/ERROR 封包交換
- 支援 block number 驗證與重組
- octet (binary) mode
- `put` 尚未實作（保留 stub）

## libnet 新增模組

### ntp.rs

| 項目 | 說明 |
|------|------|
| `NtpTimestamp(u32, u32)` | 自 NTP 64-bit timestamp 結構 |
| `NtpPacket` | 完整 NTP 封包（LI/VN/Mode/Stratum/Poll/Precision/Root Delay/Root Dispersion/Reference ID/4 timestamps） |
| `build_request()` | 構造 48-byte client request（VN=4, Mode=3） |
| `parse_packet(data)` | 解析 48-byte response → `NtpPacket` |
| `query(server)` | 查詢 NTP server → `NtpPacket` |

**測試 (2)：**
- `test_build_request_size` — 48 bytes, mode=3
- `test_parse_response` — stratum=1, mode=4

### tftp.rs

| 項目 | 說明 |
|------|------|
| `TftpError` | TFTP error code → 訊息對應 |
| `build_rrq(filename, mode)` | RRQ 封包 |
| `build_ack(block)` | ACK 封包 |
| `download(server, filename)` | 下載檔案 → `Vec<u8>` |

## 已知限制

- `tftp put`（上傳）尚未實作
- `tftp` 僅支援 octet mode
- `whois` 預設 server 僅適用 .com/.net TLD（Verisign）；其他 TLD 需手動指定
- `ntp` polling interval 固定為 5s timeout
