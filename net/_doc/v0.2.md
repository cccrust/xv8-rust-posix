# net v0.2 — TCP 工具

## 目標

實作 TCP 客戶端與伺服器工具，可在 macOS 主機上與標準 TCP 服務互動。

## 工具

### tcpclient

連接到指定 TCP port，傳送資料並顯示回應。

```
Usage: tcpclient <host> <port> [data]

# echo 服務
$ tcpclient 127.0.0.1 19999 "hello world"
Sent 11 bytes
Received 11 bytes
hello world
```

- 支援 hostname → IP 查詢
- 若有 `[data]` 引數則發送；否則從 stdin 逐行讀取
- 顯示收送 byte count
- 5 秒 read timeout

### tcpserver

監聽指定 TCP port，提供 echo/daytime/time 服務。

```
Usage: tcpserver <port> [--echo|--daytime|--time]

$ tcpserver 8888 --echo
Listening on 0.0.0.0:8888
```

| Mode | 行為 |
|------|------|
| `--echo`（預設）| 接收資料後原封不動送回 |
| `--daytime` | 連線後送回 RFC 3339 時間字串 |
| `--time` | 連線後送回 Unix timestamp |

- 每個連線 spawn 新 thread
- stderr 輸出連線/斷線日誌

## 相依性

- 純 `std::net::{TcpStream, TcpListener}` — 無外部 crate
